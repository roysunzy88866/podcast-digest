# 站点与公司 logo

这个文件夹里的图会随部署拷进站点根下的 `/logos/`,页面按**文件名**去取。
**缺文件不会出错**:图加载失败时 `<img>` 自己摘掉,露出底下画好的兜底(见下),不留裂图。

## 站名前面那个标记 —— `site.png`

顶栏站名「跨国深谈」前面那块。横版字标按**高度 28px 等比缩放**、宽度自适应。
建议给 ≥84px 高的图。没放文件时是红底白引号(引号是本站母题:每句都能回到原话)。

现在放的是用户 2026-07-27 给的 SOLO 字标(从原图上半边裁出、白底转透明、导出 96px 高)。

## 右栏「按公司」的 logo —— `<公司名小写>.png`

文件名 = 公司名转小写、空格换成 `-`。举例:

| 公司名 | 文件名 |
|---|---|
| Anthropic | `anthropic.png` |
| OpenAI | `openai.png` |
| Big Technology | `big-technology.png` |

显示成 28×28 圆角方块、`object-fit: contain`(**完整放进去,不裁**),底衬白。
方图最省事,长条图也不会变形、只是两边留白;建议 ≥56×56(2× 高清屏)。
没放文件时退回**公司名首字母**底板(Anthropic → `A`),所以可以先只喂几家、剩下的慢慢补。

改尺寸/形状去 `assets/styles/custom.scss`:站名标记看 `.mk`,公司 logo 看 `.cc .lg`。
