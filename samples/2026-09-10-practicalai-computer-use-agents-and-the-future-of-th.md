## Computer-Use:人生被改变的实操

OpenAI 最新模型(他说的版本是 5.6)发布后，配合 [[计算机使用|Computer-Use]] 技能(让模型直接像人一样操作电脑屏幕)，「我扔给它的事情几乎没有它完不成的」<button class="pd-ts" data-t="14:26" data-who="Demetrios Brinkmann" data-en="So it's like five But Yeah. So now I'd never have to worry about getting APIs for anything. I don't have to worry about, oh, but I can't reach that data because of some block or something that's wrong with it." aria-label="回原文"></button>。核心价值：再也不用为每件事找 API。他给出了几个真实工作流：

- **买机票+自动值机**：让 Computer-Use 找最好的航班，付款前由他自己点按钮；再告诉智能体「盯着收件箱，看到值机邮件就去值机，把登机牌发我手机」——全程不用问 <button class="pd-ts" data-t="18:23" data-who="Demetrios Brinkmann" data-en="I'm still afraid of that because I'm like, yeah, it can just buy something for $20 20 times, and then I'm pissed. - **德国驾照换证**：小镇政府没有 API,但有一个网页。Computer-Use 直接创建了预约、生成了日历邀请、列好要带的材料和取消号码；改期只需要说一句话 <button class="pd-ts" data-t="20:59" data-who="Demetrios Brinkmann" data-en="And saying, what does this say? - **LinkedIn 人脉整理**：LinkedIn 的 API 出了名地锁死，智能体自己发现可以下载全部数据，因 LinkedIn 要 48 小时打包发邮件，它「给自己设了个提醒，不停地查邮箱」，拿到数据后分析所有私信，筛出 500 人名单、写好个性化消息，甚至给每个人建了专属宣传网站 <button class="pd-ts" data-t="31:52" data-who="Demetrios Brinkmann" data-en="And so what I did is I told Computer-Use, I said, go and look through all my LinkedIn. ## B2B 为什么难，MCP 与 Computer-Use 的分工

to C 很美好，to B「祝你好运」<button class="pd-ts" data-t="22:38" data-who="Demetrios Brinkmann" data-en="So I just go and I I now am like, oh, right. Let's see if let's see if they can do that. Boom. ## Harness 正在被「吸进」模型里

一个更技术层的观察：实验室提供的 [[harness|harness]](围绕模型的执行框架，含工具调用、系统提示词等)与模型本身的边界正在模糊。每次新模型发布后，系统提示词越用越长；下一个模型训练时，这一大段提示词「几乎就像被 RL 进了新模型」，于是提示词又能缩短——但这个过程「会产生一些奇怪的、糟糕的东西」<button class="pd-ts" data-t="36:00" data-who="Demetrios Brinkmann" data-en="It was so good. And then somehow or another, when they r l'd this last model, and you try and bring a lot of this harness into the model, or I guess it inherently becomes blurry because they have their system prompt. Yeah. After the world uses the model for long enough, that system prompt just, like, keeps getting longer and longer and longer. Right?" aria-label="回原文"></button>。

代价已经显现：人们对 [[Claude Code|Claude Code]] 的体验非常不满，Demetrios 本人几乎停用了它——而六个月前，「Anthropic 干的所有破事我都忍了，因为他们的产品实在太优秀了」<button class="pd-ts" data-t="35:21" data-who="Demetrios Brinkmann" data-en="Hopefully, yeah, hopefully, I've I've inspired you, and please write me if you use Computer-Use and you find a rough edge where it doesn't do something. But, anyway, on the harnesses, and I wanna talk to you about is really just how much of the harness is being blurred into the actual model, it feels like, and how we've got now these, you know, like, Claude code harness doesn't there's a whole lot of things wrong with it right now today with, like, Fable and Opus five. That's, again, time stamping it. People are not happy with the Claude code experience, and I myself have pretty much stopped using it, which is wild because, I don't know, six months ago, I put up with all the crap that Anthropic was doing." aria-label="回原文"></button>。他引用朋友 Drew 转述的细节:Pi 的创造者 Mario 不得不和模型「对抗」，不让它发起 Claude Code 式的 API 调用——「我不得不和模型对抗，不让它表现得像它被训练时所用的那个 harness」<button class="pd-ts" data-t="37:05" data-who="Demetrios Brinkmann" data-en="Basically, the harness that the labs provide is very much, like, you are super optimized for the model that is that lab is putting out. It's actually like, maybe you're gonna do better on some open source models. And a lot of these open source models coming from China are really great with that." aria-label="回原文"></button>。逻辑上他仍然看好实验室：「他们拿到了所有关于人们怎么使用产品的数据」，理应做出最好的产品；但「就今天而言，情况不一定如此」<button class="pd-ts" data-t="38:32" data-who="Demetrios Brinkmann" data-en="And obviously with Codex out there, what do you think of either is the future or do you have any suggestions on where things need to go, both for users or even for the companies? 实用解法是两个社区 skill:「bro」强制模型像给五岁小孩解释一样说话，治好 Opus 式啰嗦；「show me」让它给可视化而不是写一整本书 <button class="pd-ts" data-t="40:19" data-who="Demetrios Brinkmann" data-en="I have not seen the Bro skill. What is what does that even mean? Right?" aria-label="回原文"></button>。

## 聊天是新浏览器，购物即将重构

Demetrios 在首尔和一批刚加入基金会的支付公司聊出一个判断：「聊天在某种程度上就是新的浏览器」，我们离「所有事都在聊天里完成」不远了 <button class="pd-ts" data-t="42:11" data-who="Demetrios Brinkmann" data-en="Oh, sorry to cut you off, but you know what I would love to get your take on. Some other thing that I've been thinking about deeply is really along the lines of the shopping experience and where we're going to shop in the future on the Internet. Because for me, it feels like we're not that far off from doing everything in the chat. Like, the chat is the new browser in a way. Yeah." aria-label="回原文"></button>。他抛出几个大问号：

- **电商的反击**：智能体绕过了电商二十五年优化的东西——追加销售、弹窗、「再多花 3 美元免运费」。「智能体不在乎，拿到东西就走」。所以「我们将不得不开始构建我们的电商网站来吸引智能体，而不是人类」<button class="pd-ts" data-t="45:11" data-who="Demetrios Brinkmann" data-en="And the agent doesn't care about that. Right? The agent just gets the stuff and gets out. It doesn't have that kind of discernment, at least as of now. Maybe it'll come back to you and say, oh, Chris, by the way, there's these things." aria-label="回原文"></button>。
- **[[去中介化|去中介化]]**：如果 Anthropic 或 OpenAI 说「干脆直接付给我，我做你的支付处理商」，Shopify 就被绕过了——市场变成「一个包含我所有 SKU、能被搜索、能在聊天里被购买的智能体」<button class="pd-ts" data-t="49:52" data-who="Demetrios Brinkmann" data-en="Here's here's the button. Are you okay to buy it? And we eventually click on it and say yes or no. But it's not that far off of a reality if we are living in this timeline where agents do that. When Anthropic or OpenAI, they say, well, why not just pay me directly as OpenAI?" aria-label="回原文"></button>。
- **最大的信任陷阱**：如果 OpenAI 既知道你的一切、又运营市场、每笔交易都抽成，「这难道不会激励他们只展示来自自己市场的东西？」——它两边通吃，你就没法信任它了 <button class="pd-ts" data-t="53:16" data-who="Demetrios Brinkmann" data-en="It's like, I will gladly give you anything, any information. ## 本集带走

- **遇到表单就是信号**：上网时每碰到一个要填的表单(值机、预约、注册)，先想「能不能整个任务都交给 Computer-Use」,而不只是填表那一步。

<script>
(function(){
  function fmt(s){
    if(!isFinite(s)||s<0) s=0;
    var m=Math.floor(s/60), x=Math.floor(s%60);
    return (m<10?'0':'')+m+':'+(x<10?'0':'')+x;
  }
  function wire(box){
    if(box.dataset.wired) return; box.dataset.wired='1';
    var a=box.querySelector('audio'), pb=box.querySelector('.pb'),
        bar=box.querySelector('.bar'), fill=box.querySelector('.bar > i'),
        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
