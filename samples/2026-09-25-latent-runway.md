这一集的主角是 [[Runway|Runway]] 的联合创始人 [[Anastasis|Anastasis]]——一家做了八年[[视频生成|视频生成]]模型、在 AI 行业里已经算「恐龙级」老资历的公司。

他抛出的核心主张很反直觉:视频模型不只是生成好看画面的玩具,「在预测视频时,你需要以越来越强的能力去模拟这个世界」<button class="pd-ts" data-t="24:26" data-who="Anastasis" data-en="in order to predict video well, you need to simulate the world in an increasing and increasing capacity. And if scaling laws apply on video," aria-label="回原文"></button>——用他的原话说,「我的猫咪视频和理解物理是一样的」<button class="pd-ts" data-t="31:08" data-who="Anastasis" data-en="And your answer is no, they're the same thing. My cat videos are the same as understanding physics. Right, because if you want to generate," aria-label="回原文"></button>。

## 起点:把生成模型交给艺术家

Runway 最初的论点很简单:随着生成模型分辨率和质量可预测地提升,「我们将需要重新思考创作工具是如何被打造的」<button class="pd-ts" data-t="00:45" data-who="Anastasis" data-en="of Runway was we will need as a result of those generative models rethink how creative tools are made. And as we build out the research behind our generative models," aria-label="回原文"></button>。

Anastasis 自己是艺术和工程的跨界者,早年做过画廊里的模拟社交互动装置,后来和联合创始人 Chris 用 Nvidia 早期的图像到图像模型做了 Uncanny Road 项目。

他们发现:拿一个只见过自动驾驶街景数据的狭窄模型,故意往「分布之外」推,反而能做出最有艺术感染力的东西——「如果你围绕它们构建有趣的工具并把它们交给艺术家,他们会做出你意想不到的事情」<button class="pd-ts" data-t="04:57" data-who="Anastasis" data-en="And if you look at them from another direction, if you build interesting tools around them and you give them to artists, they're going to do things that you don't expect." aria-label="回原文"></button>。

这几乎概括了 Runway 的公司理念。

早期 Runway 其实是个后期制作工具:主打叫 Green Screen 的图像/视频分割产品,替代 VFX 行业极耗人力的逐格转描(rotoscoping),后来被用进了《瞬息全宇宙》等多部高知名度影片。

## 文本生视频不是答案,控制才是

Gen 1(2023 年 1 月)是深度图条件化的视频到视频模型——因为直接做文本生视频太难,先把输入视频转成深度图、再生成像素是一个更容易的起点。

有个有趣的插曲:Gen 2 其实是 Anastasis 的一个「周末项目」——「如果我拿一个从文本输入开始并转换成深度图的模型,然后用 Gen 1 把深度图转换成 RGB,会怎么样?」

<button class="pd-ts" data-t="21:19" data-who="Anastasis" data-en="which was, what if I take a model that starts from text input and converts to depth maps, and then use Gen 1 to convert the depth maps into RGB?" aria-label="回原文"></button>这个两阶段流水线效果出奇地好,让 Gen 2 在 Gen 1 全面开放前仅两个月就发布了。

而今天人们又在回归两阶段方法:Reeve 文生图模型先用 Planner 生成边界框再交给扩散模型,Ideogram 同一天也推出了同样的创新。

学到的最大教训是:「文本生成视频不会是答案。人们想要比那多得多的控制力」<button class="pd-ts" data-t="19:04" data-who="Anastasis" data-en="I think the biggest one was it was very clear early on that text-to-video was not going to be the answer. People wanted a lot more control than that." aria-label="回原文"></button>。

于是 2023 年一连串控制手段快速推出:Motion Brush(画箭头指定物体运动方向)、镜头控制(描述相机如何移动)。

镜头控制尤其重要——它第一次让人感觉不是在剪辑,而是在世界内部导航,这成了后来[[世界模型|世界模型]]研究方向的种子。

另一个行业公开的秘密是:「每一个投入生产的视频生成模型,在底层都用了一条复杂的提示词补全流水线」<button class="pd-ts" data-t="22:39" data-who="Anastasis" data-en="And obviously now, every single video generation model in production uses a complex prompt completion pipeline under the hood." aria-label="回原文"></button>——因为人类写提示词太糟糕,模型会先重写你的描述。

## Sora 危机与 Gen3 的三个月冲刺

Sora 发布时,「Twitter 上有很多关于 Runway 的议论:Runway 完了。Runway 不可能追上来了」<button class="pd-ts" data-t="36:44" data-who="Anastasis" data-en="There were a lot of chatter on Twitter about Runway. Runway's done. There is no way Runway will catch up." aria-label="回原文"></button>。他坦承有几小时像经历了存在危机。

但公司随即把模型规模和训练算力扩展了 10 倍,从零学起了模型并行(当时团队「在那方面是零专业积累」),三个月冲刺后推出了 Gen3。

他回忆那是公司最大的转折点,「如果你问任何一个在那个时期待过的人,他们在 Runway 最喜欢的时光,就是那三个月左右的冲刺,做出一个比 Sora 更好的模型」<button class="pd-ts" data-t="37:39" data-who="Anastasis" data-en="If you ask anyone what is their favorite time at runway that was there during that time, it was that push in like three months to get to a model better than Sora." aria-label="回原文"></button>。

几个月后他们又发布了 Turbo 版本——第一个在生产环境中使用的步数[[蒸馏|蒸馏]]模型。

在他看来,「[[实时视频生成|实时视频生成]]是不可避免的,它的用户体验要好得多,服务成本要低得多」<button class="pd-ts" data-t="41:26" data-who="Anastasis" data-en="you know, two years from now, we Don't primarily use real-time models. To me, real-time video generation is just inevitable that it has much better user experience." aria-label="回原文"></button>;蒸馏方法(把多步扩散压缩成少步生成,类似把大模型压缩成小而快的版本)有两个维度——压缩模型大小,或压缩步数,而他们发现很多时候可以直接用前沿大模型做到实时。

关于 LeCun「理解世界动态和生成可爱视频是完全不同的事」的批评<button class="pd-ts" data-t="30:53" data-who="Anastasis" data-en="you know, there is that counter argument that I think there was a tweet by Jan LeCun a few days ago that," aria-label="回原文"></button>,他的回应是:语言模型从勉强连贯的句子走到能自主写一整天代码,主要靠的是规模而非架构革命;他们有 PhysicsIQ 这类衡量经典力学、流体动力学的基准,「随着计算规模扩大,物理 IQ 的得分可预测地提升」——「即使仅仅靠规模扩展也能帮助模型更好地学习物理」<button class="pd-ts" data-t="33:35" data-who="Anastasis" data-en="tricks and techniques that you can make to improve the score even further, but even scale alone helps in the model learning better physics. My main sympathy with Jan LeCun is the Plato's cave allegory, right?" aria-label="回原文"></button>。

他承认 Gen2 时代的画面确实像「几乎无法生成连贯句子的 GPT-2」——「但如果你把它扩展,从某种意义上说没有理由它不会成功」<button class="pd-ts" data-t="26:20" data-who="Anastasis" data-en="The idea was that's just GPT-2 and GPT-2, you can barely generate coherent sentences. Similar Gen2 can barely create coherent video, but if you scale it up, there is no reason why it shouldn't work in a way." aria-label="回原文"></button>。

Runway 的思维方法一直是外推:看趋势,而非只看当下结果。

## 接口世界模型:直接生成像素

最惊艳的演示是「接口世界模型」:一个软件界面,没有任何 HTML、CSS、React 驱动,「这直接是我们实时视频生成模型的输出,它直接把点击、拖拽和滚动作为输入」<button class="pd-ts" data-t="43:59" data-who="Anastasis" data-en="There is no HTML, CSS, React that's powering this interface. This is directly at the output of our real-time video generation model, and it takes clicks directly as input." aria-label="回原文"></button>。

理念是「为什么要生成能生成像素的代码?直接生成像素就好。这是把端到端哲学应用到前端上」<button class="pd-ts" data-t="45:14" data-who="Anastasis" data-en="Just render. Why generate the code that generates the pixels? Just generate the pixels directly." aria-label="回原文"></button>。

你可以在提示词里直接描述交互行为——「如果我按这个按钮,就应该发生这个」——做原型、教育可视化、甚至按访客做个性化(比如放大字号做无障碍)都变得容易。

终极形态是「一个全神经的操作系统」<button class="pd-ts" data-t="50:26" data-who="Anastasis" data-en="Effectively, the end game of something like interface world models is you have a fully neural operating system." aria-label="回原文"></button>,并重新思考「应用程序」这个抽象本身。

成本显然更高,但团队策略是先找到明显比传统界面更有说服力的场景,降本交给时间。

## 意外做成了机器人领域的 SOTA

更硬核的方向是[[机器人|机器人]]。因为在扩展视频模型,「我们意外地创造了一个机器人领域最先进的模型——仅仅通过扩展视频模型」<button class="pd-ts" data-t="56:04" data-who="Anastasis" data-en="One thing we like to say is we, as we scaled video models, we accidentally created a state of the art model for robotics." aria-label="回原文"></button>。

GWM Robotics 从基础视频模型出发,只微调非常少量小时数的机器人数据就有相当好的表现。

核心论点关乎数据来源:遥操作数据需要真硬件难规模化,第一视角数据「比世界上现存的[[第三人称视频数据|第三人称视频数据]]少了三个数量级」<button class="pd-ts" data-t="61:55" data-who="Anastasis" data-en="which requires actual hardware, It's still three orders of magnitude less of that that exists in the world compared to third-person video data out there." aria-label="回原文"></button>,而「最丰富的视频数据来源是第三人称视频数据」<button class="pd-ts" data-t="60:52" data-who="Anastasis" data-en="and all those are great source of data for training robotics models, but the most plentiful source of video data is third-person video data. And how do we as humans learn how to perform different tasks?" aria-label="回原文"></button>——正如人类学习,「我们是通过观察别人做来学习的」<button class="pd-ts" data-t="61:12" data-who="Anastasis" data-en="But ultimately, a lot of what we learn how to do in the world, we learn by watching other people do it." aria-label="回原文"></button>。

世界模型还解决了传统模拟器的痛点:布料、湿滑表面等复杂物理很难人工建模,而世界模型只需给环境拍一张照片就能展开策略测试。

他们已验证了模型与现实之间很好的相关性(在常用的机器人基准设置下)。

下一站是「世界动作模型」:给视频模型加一个动作头,生成足够精确的视频,就能反推出机械臂应有的 3D 姿态,模型本身变成策略。

与纯视频模型的关键差距在[[反事实生成|反事实生成]]:训练数据里成功进球的视频远多于失败,所以模型更擅长生成成功;但交互式世界模型必须「生成同样逼真的结果」——不论你选哪个动作。

「视频模型与世界模型之间的巨大差距,就在于反事实生成这个理念」<button class="pd-ts" data-t="70:15" data-who="Anastasis" data-en="you want to generate equally realistic outcomes. So that's, I think the big gap between video models and world models is that idea of" aria-label="回原文"></button>。

他的思想实验:戴上 VR 头显走动、与物体互动,最后你分不清看到的是透视实拍还是实时生成——「那就说明这些模型已经变得足够好了。

而我们离那一步还很远」。

> 【背景】LeCun 全名 Yann LeCun,Meta 首席 AI 科学家,长期主张视频生成不足以学会世界模型,需要 JEPA 等新架构。嘉宾示范的界面世界模型、GWM 系列、以及与 NVIDIA 共同发起的开源 Cosmos Coalition(开放权重、物理基准、基础设施)都出自本集对话。

对艺术圈对 AI 的抵触,他的看法是:当工具提供多达 50 个参考输入、充分可控时,「它感觉更像一个工具,而不是某种神奇的实体,会替你搞定你的整部片子」,抵触情绪因此明显缓和。

创作侧的迭代重点也从质量(已大幅提升)到可控性,再到延迟——「Photoshop 是即时的」,实时模型要把这种即时魔力带回生成领域。

行业争论仍很活跃:VLA 与世界动作模型之争、遥操作数据与视频数据之争、直接预测像素是否正确,而人才招聘上他们明确在扩研究、机器人(软件/硬件/研究)和市场化团队。

## 本集带走

- **看趋势不看快照**:Runway 的方法是把当前结果外推——Gen2 之粗糙好比「只能生成勉强连贯句子的 GPT-2」,但[[缩放定律|缩放定律]]成立时,没有理由它不会成功。
- **控制力比一次成型重要**:纯文本生视频已被证明不是产品答案;相机轨迹、初始帧、参考图、多达 50 个参考输入才是让电影人真正可用、也让公众抵触降温的关键。
- **脚手架终将被吸收进模型**:从思维链提示到多镜头视频生成,「需要外部 harness 做的事,最终会被注入模型本身端到端学习」。
- **视频模型到世界模型差在反事实**:不仅要会生成「成功进球」,还要同样逼真地生成「失败」——这对评估和在线 RL 都必不可少。
- **数据生态位决定胜负**:机器人领域第三人称视频比第一视角数据多三个数量级,预训练看视频、少量机器人数据微调,就能得到可用的操作策略。
- **前端的端到端时刻可能来了**:界面不必经代码再渲染像素,直接由实时视频模型按点击/拖拽/滚动生成——原型、教育、个性化是新入口,成本是主要待解项。

    return (m<10?'0':'')+m+':'+(x<10?'0':'')+x;
  }
  function wire(box){
    if(box.dataset.wired) return; box.dataset.wired='1';
    var a=box.querySelector('audio'), pb=box.querySelector('.pb'),
        bar=box.querySelector('.bar'), fill=box.querySelector('.bar > i'),
        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
