I'm a solo founder girl." aria-label="回原文"></button>。说这话的是 Jana Wellander，她在做一个叫 [[Yanabana|Yanabana]] 的 AI 原生时尚品牌，AI 不只是辅助工具，是她事实上的技术联合创始人 <button class="pd-ts" data-t="03:14" data-who="Unknown" data-en="And the idea is to use AI really anywhere in the process where that makes sense. So obviously heavily in the design and production process, but also it's literally my technical co-founder." aria-label="回原文"></button>。

## 从草图到成衣：AI 怎么插进设计流程

Jana 的大多数设计从手绘草图开始，老派的那种。然后她把草图喂给 [[ChatGPT|ChatGPT]] 的图像生成（用的是 Images 2.0），让它转成产品照片、T 台照、网红风格照等不同类型的宣传素材 <button class="pd-ts" data-t="04:07" data-who="Unknown" data-en="So I start with a hand-drawn Humanly, manually, you know, old school hand drawn sketch. And then I use AI to turn that into different types of fashion collateral and kind of technical specs and everything along the line to ultimately get to a garment." aria-label="回原文"></button><button class="pd-ts" data-t="08:39" data-who="Unknown" data-en="So once we have this ready, I will ask it to ...generate a Vogue-style runway photo. Oh, there we go." aria-label="回原文"></button>。

为什么选 ChatGPT 的图像模型而不是别的？她试了大量图像模型，发现一个关键差异：其他模型能生成漂亮逼真的图，但会偏离她的原始设计，做出「看起来像之前某个 T 台上见过的东西」 <button class="pd-ts" data-t="11:21" data-who="Unknown" data-en="Like this is kind of why I have this, this very detailed kind of prompting where I tell it how the fabric should flow, because otherwise it can get into the mindset of, oh, she really wants it to look like paper, you know." aria-label="回原文"></button>。

而 ChatGPT 的模型最擅长遵循视觉指令，能紧紧贴合她的草图 <button class="pd-ts" data-t="10:31" data-who="Unknown" data-en="And what I found was ultimately NanoBanana and Image 2.0, really Image 1.5 was already pretty good at this. ...are the best at following visual directions. And often I'm not doing this." aria-label="回原文"></button>。甚至有时候贴得太死，把面料画得像纸，她还得在[[提示词|提示词]]里专门写明面料应该如何流动、如何垂坠来纠正 <button class="pd-ts" data-t="11:01" data-who="Unknown" data-en="In fact, it follows the sketch sometimes a little bit too precisely. And so you get something that doesn't look like fabric anymore and you have to kind of be like, no, no, no, no, no." aria-label="回原文"></button>。

她的提示词不是随便写几句，而是像写产品规格说明一样，定义「什么是一件好的成衣/照片」：轮廓、比例、体积、面料流动方式、结构细节、运动方式，甚至声音 <button class="pd-ts" data-t="07:03" data-who="Unknown" data-en="Thank you for watching. The silhouette, the proportion or the volume of the dress, like kind of like the fabric, how it flows, how it behaves, the construction details, how it moves, even how it sounds." aria-label="回原文"></button>。主持人 Claire 总结了一个通用方法论：**写下你的流程，写下「完成」或「好」的定义**——你为 AI 写的 spec，其实也是给人类做这件事需要的同样信息 <button class="pd-ts" data-t="11:52" data-who="Unknown" data-en="I don't have any use for this. What I think is the takeaway here, generally for folks, is write down your process and write down what a definition of complete or good is." aria-label="回原文"></button>。

## 以前造不出的衣服，现在能造了

有一件裙子不是从草图来的。Jana 那天在好几个地方碰巧看到艺术家 Ruth Asaba 的线圈线雕塑作品，灵感来了，直接让 AI 生成一张模特穿着受这些雕塑启发的裙子的 T 台照 <button class="pd-ts" data-t="15:01" data-who="Unknown" data-en="I'm doing and so to give you an idea from one of these so for example I had this dress that actually did not come from a sketch it came from I had this one day where I was just being" aria-label="回原文"></button><button class="pd-ts" data-t="15:33" data-who="Unknown" data-en="I didn't have a sketch, right? Normally I start with a sketch, but in this case, I was like, you know, make a photo of a model walking down the runway in a dress inspired by Ruth Asaba's loop wired sculptures." aria-label="回原文"></button>。

这件衣服她定义为「以前无法制造的」 <button class="pd-ts" data-t="16:56" data-who="Unknown" data-en="A lot of garments you would do like some garments I will drape right like on the model behind me or some garments go into they become you create a kind of a pattern and I have different some AI processes and some non-AI processes that I've done for patterns." aria-label="回原文"></button>。不是 3D 打印技术做不到，而是创建那些球形装饰件的 CAD 模型极其繁琐，人工做的话她可能直接放弃了 <button class="pd-ts" data-t="18:05" data-who="Unknown" data-en="I had to do, this is a really, really long process. And then ultimately I had it using computer use, go and build this in 3D software so that I could create like an .ncl file and send off to 3D print." aria-label="回原文"></button>。

她的做法是：先把 AI 生成的图转成草图，再转成更详细的插画，然后让 Codex 用 [[计算机使用|computer use]]（一种让 AI 像人一样操作电脑软件的能力）直接在 3D 软件里建模，最终导出文件送去 3D 打印 <button class="pd-ts" data-t="18:00" data-who="Unknown" data-en="We had a bunch of back and forth. Eventually it started doing something that was a little bit more similar. I had to do, this is a really, really long process." aria-label="回原文"></button><button class="pd-ts" data-t="18:05" data-who="Unknown" data-en="I had to do, this is a really, really long process. And then ultimately I had it using computer use, go and build this in 3D software so that I could create like an .ncl file and send off to 3D print." aria-label="回原文"></button>。

这里有一个她觉得非常重要的发现：Codex 单独生成最终 CAD 文件效果不好，但让它通过 computer use 去操作专业的 3D 软件，效果就很好 <button class="pd-ts" data-t="19:45" data-who="Unknown" data-en="I think that that's a great point. And one fascinating piece is that a lot of these things, like, for actual end product, like a CAD file, Codex, as amazing as it is, is not great at generating a final CAD file if you ask it to do it on its own." aria-label="回原文"></button>。她还用同样方式让 Codex 操作一个叫 Clo 的服装软件来生成版型并贴合到 3D 模型上——一个她自己都没学会用的软件 <button class="pd-ts" data-t="20:17" data-who="Unknown" data-en="But if you use, yeah, if you use computer use and have it go and do it in a piece of software that's designed for that purpose, and I have both for like actually for 3D printing and there's a fashion" aria-label="回原文"></button><button class="pd-ts" data-t="20:25" data-who="Unknown" data-en="And it generates patterns and it then fits them on the 3D model. And I tell Codex to go and use this software that I haven't learned how to use myself. And it does such a great job at something that it itself couldn't do." aria-label="回原文"></button>。

这让她得出了一个判断：**SaaS 没死，只是使用者变了**。[[智能体|智能体]]很擅长「按按钮」，所以软件回来了，但变成智能体在用 <button class="pd-ts" data-t="19:34" data-who="Unknown" data-en="You know what? Like, agents are really good at pressing buttons. So, like, a software is back, but agents are going to use it." aria-label="回原文"></button>。

## 找工厂、发邮件：AI 包揽所有杂活

设计完要生产，她让同一个工具变成研究助手：找 10 家美国本土的定制服装制造公司，启动深度研究，然后她自己去缝纫机前做原型，等研究跑完再通过语音回来检查结果 <button class="pd-ts" data-t="21:09" data-who="Unknown" data-en="Yeah. So for something like that, what I've done, and I do this a lot, is I will go and now this same tool becomes my research assistant and I ask it to identify, like," aria-label="回原文"></button><button class="pd-ts" data-t="21:55" data-who="Unknown" data-en="For a lot of my work, I end up like I'm doing something else. So I'm like, I am kicking off this research and then I go and like drape fabric on model or I do like I'm on my sewing machine doing prototypes, like I'm doing something else." aria-label="回原文"></button>。

下一步是联系工厂。她让 AI 起草邮件，然后用 [[浏览器使用|browser use]]（类似 computer use，但操作的是浏览器）进到她的邮箱里设置好所有邮件，但她坚持自己点发送按钮之前检查一遍 <button class="pd-ts" data-t="22:18" data-who="Unknown" data-en="And so like in this case, I came back to it and I was like, well, do you see the, because I'm talking. I've been using voice, right? Like the apparel manufacturers that I asked you to find." aria-label="回原文"></button><button class="pd-ts" data-t="22:32" data-who="Unknown" data-en="Now can you like put together an email that you can send off to them, but like you may want to make sure that you get my approval to do that. And then I use browser use to let it go into SuperHuman and like set all of these up for me, but I really want to click the send button before." aria-label="回原文"></button>。

她说如果没有 AI 干这些枯燥的活儿，她在「找工厂」这一步就会直接放弃，因为太无聊了 <button class="pd-ts" data-t="23:04" data-who="Unknown" data-en="And they're like, oh, I have to like look up. ## 本集带走

- **把「好」的定义写进提示词**：不要泛泛地描述，像写产品 spec 一样列出具体维度（轮廓、比例、面料表现、结构细节等），AI 和人类做这件事需要的信息是一样的。
- **选模型看「遵循度」而非「好看度」**：能生成漂亮图的模型不等于能忠实还原你的设计，时尚设计领域尤其如此——你要的是新东西，不是最像已有作品的那个。
- **AI 不擅长直接生成最终文件时，让它操作专业软件**：Codex 自己出 CAD 文件不行，但通过 computer use 操作 3D 建模软件就行。关键是今天就能用，不用等模型本身变强。
- **把枯燥的执行链拆给 AI，自己只做决策节点**：找供应商、起草邮件、设置发送，AI 全能做，但发之前你自己过一遍。这样不会在无聊环节放弃。
- **SaaS 没死，使用者从人变成了智能体**：软件的价值还在，只是入口变了。
