# 从 NFL 超级碗到 40 亿美元基金：运动员如何真正做好风险投资

这一集的主角叫 Ryan Neese——他打过 [[NFL|NFL]]、拿过超级碗，退役后联合创办了投资机构 [[NextLegacy|NextLegacy]],如今管理规模已接近 40 亿美元。而他父亲的名头更响：一位赢过四次超级碗的名人堂级安全卫。

更巧的是，父亲的退役之路和儿子几乎走的是同一条：打球、进硅谷、做投资。Ryan 从小被父亲拽去咖啡店开会、被要求记笔记，「有机会聆听未来」。

他在 UCLA 读书时就开始看 Cisco、Intel 这些当年的前沿公司；进了 NFL 后第一年就在 [[Tampa Bay Buccaneers|Tampa Bay Buccaneers]] 拿了超级碗——那支防守组里有四位名人堂球员；最后一站在 [[Detroit Lions|Detroit Lions]],打出 0 胜 16 负。他自己调侃：「我可能是 NFL 历史上唯一一个第一年赢超级碗、最后一年 0 胜 16 负的人」——最好和最差的球队都待过，两极视角极其难得。

## 精英运动员和精英创始人，区别就在一个词

Ryan 花了很多时间想用一个词概括他见过的顶级运动员、创始人和投资人的共同特质，最后得出的是「thoughtful」——体贴入微、用心至深：注重细节，做到的不只是最低要求，还沉浸在当下的细节里不断改进，甚至总觉得自己不够好、不断迭代。身在这样的环境里，你会学到「成为伟大需要什么，以及为此必须付出什么」。

他还强调一个常被低估的点：职业体育不是「运球投篮」那么简单。你是在保持巅峰体能的同时下棋——极端程度的多学科多任务，对手也在思考。

他引用冰球名宿 Wayne Gretzky 的名言「不要滑向冰球所在的地方，要滑向冰球将要到达的地方」，并拆解出三层能力：反思过去、理解当下、预测未来——这恰恰也是创始人每天都在做的事。而体育和风投共享另一种稀缺品：速度。顶级创始人的处理速度、在信息不完善时快速做出正确决策的能力，正是他物色合作者时找的信号。

## 运动员入行的最大坑：没有判断力，只认名气和粉丝量

现在的运动员随时被人私信、被各路人接近，行业门槛比当年「想见 Bill Gurley 一面都难」的时代低了太多。Ryan 观察到最常见的坑是：运动员没有足够的经验去判断「我到底该信任谁」。

很多人有个「中间人」，一问是谁——在 Google 工作，但「可能离事情真正发生的中心有点远」。另一个危险模式是把投资完全当副业，派代表去开会、自己不露面——「那些就是我们见过的灾难配方」。真正有长进的，都是本人出现在会议里、花时间、投入学习的人。

他也点破一个行业的暗面：很多人接近运动员，不是在帮你，而是在「牺牲你的利益来抬高自己」——借你的名气为自己抬轿子。所以他给运动员的甄别三问很具体：第一，「你以前做过这件事吗？

」；第二，如果做过，「你现在还在和那些人合作吗？」；第三，「你为什么想要这个？

计划是什么？」——不只看今天，要看三五年后，然后就可以拿这个计划让对方负责。

主持人 [[Turner|Turner]] 补了一个自己的技巧：问「你的客户留存率是多少」——从不流失未必是好事，答不上来往往是因为所有人都走了。Ryan 还补了一条：看费用结构。

「你真正想要的是，和你合作的人只在你赚钱的时候才赚钱。」激励不对齐就是危险信号。

最糟糕的投资决定，他见过太多：把钱投进夜店、餐厅这类生活方式生意，或者「只想快速倒手一下」。「任何时候只要是快的，它进得多快，大概率就会消失得多快。」谁给你展示一个「很短的机会窗口、很快燃尽的引线」，那就是灾难配方。

## 运动员能真正帮创始人什么

不只是名气和分发渠道。Ryan 总结了三种被验证的价值：一是分发和形象大使；二是开门——运动员的人脉能帮 CEO 见到他们努力多年都见不到的客户和合作伙伴；三是最被低估的部分：做参谋。

运动员经历过最混乱复杂的环境并学会快速决策，而运动员和创始人之间有一种共同语言——「渴望实现不可能」。运动员一生都被告知「你不可能成为职业运动员」，创始人都被告知「这想法永远行不通」，然而他们都闯过来了。两个人坐在一起，会产生一种「铁磨铁」的氛围。

他举了 Gretzky 式的例子说明这种判断力怎么来的：在 Tampa 的线卫首发第一年，对阵 Carolina Panthers,他预判了对方跑卫的路线、冲出防区想制造集锦，结果对方切进他放空的空档一路冲到底——队友 Warren Sapp 一边全场回追一边当场骂他。妙的是，「Warren 到底是怎么知道是我放空的？」这就是顶级球员的实时判断力——和顶级创始人的处理速度同源。

## 幂律：风投和体育是同一种游戏

主持人提出风投的[[幂律分布|幂律]]——大约 90% 的回报来自 5% 的公司或基金。Ryan 认为体育完全一样：打过 NFL 的男人总共大约两万五千人，过半连三年半都打不满，这本身就是幂律和离群值。

而「即使在精英中的精英里，仍然存在幂律」——就像 F1 里多年只押 Lewis Hamilton、网球里先是 Sampras 后是费德勒，总有人以压倒性的持续性统治领域。他引用斯坦福研究：过去 10 年风投 90% 的回报来自 5% 的基金。

落到操作层面，每年有上万家公司成立，「但每一年到下一年真正重要的只有大约 10 到 20 家」。你如何拿到接触机会？

他的答案是「成功自有迹可循」：去研究这个行业的历史，理解幂律，研究 Sequoia、Andreessen 这些顶级机构为什么持续保持最高水平，再研究标志性公司为什么持续跑赢。核心是打磨「味蕾」——他拿自己举例：小时候能吃一次 Sizzler 牛排就觉得中了彩票，但后来接触了更好的地方，Sizzler 的排名就降了。

「你必须打磨并校准你的味蕾，让你有能力找到并接近这个行业最顶尖的公司和人物。」没机会像他那样耳濡目染的人，可以申请 NextLegacy 的研究员项目(为期一周)，回学校读商学院，去读 Andreessen 这类多产投资人的博客，去 CES、TechCrunch 这类大会钻进独特的圈子。

还有一个他反复强调的基本功，简单到令人惊讶：投资前先去用产品。还有人连会面前先搜一下对方都不做。他当年打 NHL 圈外的冰球时发现自己只有速度、现在没那么快了，感慨「如果能拥有现在 35 岁的头脑，还能保持 17 岁的滑行速度就强得不得了」——对应到风投，预判和速度缺一不可。

## 不收 carry 的基金：钱都捐给慈善

NextLegacy 的模式在风投圈近乎异类：旗舰基金不收 carry(业绩分成)。原因在于它的前身 [[Legacy Ventures|Legacy Ventures]] 是 Russ Hall 创立的，模式从诞生之初就是这样——投资人的全部收益导向慈善事业：捐赠基金、基金会、公益组织，GP 的收益也全部捐出。

2014 年 Ryan 创立 [[Nextplay Capital|Nextplay Capital]],2020 年两家合并。「这些年来，我们已经向世界各地致力于让世界变得更好的不同组织分配了超过 30 亿美元。」他明知大多数 VC 听了会觉得疯狂，但这是他的初心：创立公司时他只知道「我想要满足一种需求」——很多运动员和普通人没有席位，却想进入那个房间、和最顶尖的人在一起。

> 【背景】Legacy Ventures 由 Russ Hall 创立于 1999 年(此年份为本段模型背景知识，未在本段原文中出现)。

募资这条路上，他吃过最多的亏也总结了最多的方法。早期最大的错误之一是没花够时间在幕后事务上——法律、合规、基金行政管理这些琐碎，「就像你寻找下一个投资机会一样深入」，后来不得不推翻重来。

他学会的最值钱的一个问题，几乎是每次必问：「能否带我走一遍你们拿到一个 yes 所需要的流程？谁需要参与决策、典型时间线是什么？

」——问完你才知道对面的人可能根本不是决策者。他也领悟到募资是长跑，「在一个小时之内，你不会给我一千万美元」，所以要「以一种深思熟虑但不烦人的方式」持续经营关系。

他总结出「三的法则」：一次投缘的会面、两天后在另一个圈子的自然相遇、行业里可信的人主动提起——三个触点之内，LP 的天线就竖起来了。这背后的机制是：LP 们极其爱八卦，尤其在年度会议季互相交换笔记、互相做背景调查，「你越能帮助把信息传播到那些[[耳语网络|耳语网络]]里，它就会传播得越远」。而让耳语网络替你说话的方式没法人为设计，靠的是「给予之手永不空乏」——不断给 Bill Gurley 送项目也不求回报，因为你相信它会有回报。

在筛选[[新兴管理人|新兴管理人]]上，他们的方法论：去年对 430 多个管理人做了深度尽调，Alpha 大致来自「杠铃」两端——一端是有护城河、能持续赢得顶级项目机会的蓝筹机构；另一端是微型但有特定专长、差异化网络的新管理人。大型 LP 想要后者的敞口，却受限于支票下限(不写小于 2000 万美元的支票)和不超过单只基金 10% 的规则，于是需要 NextLegacy 这样的中介。

看人时他有个「首发五人组」法：你最愿意一起投资的五个人、花时间相处的五个人、常去的五个地方——看完这些，你对这个人及其网络就有了相当不错的判断。在 AI 不断把信息和数据商品化的时代，「拥有差异化的网络、能接触到别人接触不到的信息」就是优势——他把这叫第二种 AI:「真实互动」(authentic interaction),在对话进入互联网、被录制转写之前就获得信息。

## 0 胜 16 负教会他的事

那支 0-16 的雄狮队赛季中途解雇了总经理，还在合同期内的球员被直接赶回家。他记得从第三周开始，脑子里每天冒出同一个念头：「今天不可能比昨天更糟了吧。

」然后每天都更糟一点。正是在那里，他悟出了后来公司的名字 Nextplay。

他打电话向父亲求教怎么走出搞砸的阴影，父亲的回答成了这一集的点睛：「Ryan,这就是全部的关键所在。那个球已经不存在了。

它结束了，它消失了，它被忘掉了。」在父亲的脑子里，那球根本没发生过。

他总结：无论体育、商业还是个人生活，「处理当时的处境——无论好坏——然后向前走的能力真的很重要」。留在后视镜里太久，你会忘记看前挡风玻璃。

怎么在持续低迷中保持信念？他引用 Napoleon Hill 的《Three Feet from Gold》:很多人离目标只差三英尺，却在最艰难的时刻放弃了。

一个诀窍是回看你已经克服过的东西；另一个是他练习心理韧性的笨办法：每个月挑一个极小的任务——用左手开门、单脚刷牙、写一封信——整整一个月每天必须做。事情本身不难，难的是「提醒自己每天都要做这件事」，在有干扰、想上床睡觉的时候依然坚持。这样等事业上真正艰难的时刻来临，他会记得：坚持下去，能到另一边。

他还讲了母亲的那堂课：小学时他吹嘘自己踢足垒球多厉害、当队长只挑最强的孩子，母亲问「如果你真有你说的那么厉害，你就应该先选那个没被选上的孩子，再组建你的队伍——如果你能带着他们赢，那你才是真的厉害」。他选了那个孩子，那种「看到另一个人被看见、被托举起来」的感觉让他记了半辈子。

而现在，他相信一句「我看见你了」、一句真诚的鼓励——就像 Turner 大学时被学长一句十秒钟的「你应该去竞选会长」推上轨道——「能突然把你送上一条你根本没想到自己会走的轨迹」。被他问及最崇拜的人时，他没说父亲，说的是 Jerry Rice:训练中每次接球都完美接住、每次都全速冲刺到端区达阵、随时用脚在横线上打磨步法——「每次我碰到球，我就要得分，而且我要照这样去练习」。

## 本集带走

- **入行三问甄别中间人**：你以前做过这件事吗？现在还在和之前的客户合作吗？你为什么想要这个、三五年后的计划是什么？
- **激励必须对齐**：看对方怎么拿钱——预收大额费用、事后再干活的结构是危险信号；理想状态是「你赚钱他才赚钱，你赚得越多他赚得越多」。
- **远离「快钱」**：短窗口、快引线的机会，进得多快就消失得多快；夜店餐厅类生活方式生意是他见过最多的翻车现场。
- **投资前先当用户**：产品一定要亲自用，会面前先做基本搜索尽调——这些最简单的事反而最少人做。

        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
