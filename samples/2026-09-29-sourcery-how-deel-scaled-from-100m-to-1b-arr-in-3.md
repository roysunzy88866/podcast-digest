# Deel CRO：三年从 1 亿到 10 亿美元，靠的是敢卖

这一集是在 Strike Summit 现场的一场对谈，聊的是[[销售|销售]]和增长——主角是 [[Shuo|Shuo]],全球薪酬与人力资源平台 Deel 的 CRO。Deel 帮公司在全球范围内招聘、管理、发工资，业务覆盖 160 个国家，估值 173 亿美元，ARR(年度经常性收入)最近突破了 15 亿美元。它最惊人的增长轨迹是：20 个月从 100 万销售额做到 1 亿美元，然后只用了三年——主持人一开始说五年，Shuo 当场纠正——从 1 亿美元做到 10 亿美元 ARR。

她在节目里被反复追问的，正是她在另一场活动上给出的「最劲爆观点」，而且收尾时她原样又说了一遍：**人们需要更多地销售。**「人们拼得还不够狠，没有尽全力去获取收入或客户。

」主持人补充了一个现场观察：无论在度假、在夏威夷还是在这场峰会上，只要坐上一张晚餐桌，Shuo 都会试着向同桌的人推销，而且事后一定跟进。她的观点很直接：如果你是一名创始人，你身边有那么多潜在客户——那么多创始人、那么多家族办公室——不去卖就是浪费。

## 为什么第一天就做全球

Shuo 是工程师出身：在 MIT 做机器人，第一家公司里她是 CTO,设计过大型机器。她说自己从没想过会去负责收入、管理庞大的销售团队，但底层逻辑是一样的——**全都是[[构建系统|构建系统]]，全都是尽可能科学地做事**：理解客户想要什么、为他们设计最好的产品；同时理解销售团队想要什么、找到激励他们的方法。

Deel 从第一天起就是[[全球化|全球化]]的，这和很多硅谷公司「先深耕一个国家再扩张」的路径完全相反。原因一半在产品，一半在人：她和联合创始人 Alex 都是移民——她在中国出生长大、16 岁去美国，Alex 是法国人、19 岁去美国。

这让他们很早就意识到，世界很大，优秀的人才不只集中在一个城市，他们想做的是让每个人无论身在何处都能找到最好的工作。这也直接定义了 Deel 的商业模式：160 个国家，每个国家都有自己的法人实体、合规团队、薪酬团队、税务和法务，自动化和产品全部自建。客户名单也够硬：Eleven Labs、Chanel、大量 AI 公司，还有银行和风投机构。

> 【背景】转写稿把这个公司名听写成了 Deal/Dio,实际是 Deel——一家以「全球雇佣与发薪」为主业的独角兽公司。

## 完全远程的千人销售团队怎么带

Deel 的销售团队完全远程，分布在 120 个国家。Shuo 认为关键有两条。

第一是钱：销售提成必须足够，确保他们真的能赚到很多钱，「非常非常重要」。第二是文化：建立一种赢的文化、持续创新和持续向市场交付最好产品的文化，团队自然就凝聚了——所有人都专注于同一个目标。

落地动作是每年一次的 Deel Kickoff:近 1500 人飞到同一个城市，关起门来整整五天，把新年目标、产品重点、战略全部对齐，并确保每个人都「超级兴奋」。

营销上也打得很开。最近的一项活动是和 Snoop Dogg 合作：Deel 帮他在全球招聘冰淇淋品鉴师，月薪一万美元。Shuo 借这个例子把全球化主张又推了一层：今天你建公司、建品牌，就必须瞄准全球市场——连 Snoop Dogg 都在走向全球，而且你会增长得快得多。

## 榜样：Dyson 的偏执与 Bezos 的自我重塑

谁塑造了她的做事方式？第一家公司受 James Dyson(戴森创始人)启发：他做的每样东西——吸尘器、空气净化器、吹风机——都从一个非常简单的想法出发，痴迷于解决一个非常具体的工程问题，然后把产品做到完美。

「我今天刚看到他要去推出一把牙刷，500 美元的牙刷，但我会成为头号客户。」

而在公司规模化这件事上，她最服 Jeff Bezos:那张著名的照片——手写的 Amazon 招牌、一张小桌子、周围没人，一个人专注地构建。她欣赏他是顶级的系统性思考者、有远见、且一直在自我创新。由此她给出对创始人的忠告：**你最大的竞争对手是你自己**，你必须持续创新、持续重塑自己，才能持续交付。

收尾时她还留了一个观察：峰会所在的这个地区(相对旧金山)一切都慢，而旧金山一切都在为效率优化——「AI 有很大潜力，但 AI 还没有征服世界的这个地区，所以我们有很多东西可以建。」

## 本集带走

- **创始人该亲自去卖**：潜在客户就在身边——同行创始人、家族办公室、每一张晚餐桌——拼得不够狠、不跟进，就是浪费机会。这是 Shuo 两次被问都原样重申的观点。
- **销售和造产品是同一套逻辑**：理解客户要什么、设计最好的产品；理解销售团队要什么、用激励把他们武装起来——本质都是构建系统、科学地做事。
- **远程千人大团队的两根支柱**：提成确保销售真能赚到钱(她认为这极其重要)，再加上「赢」的文化；然后每年一次五天、1500 人的 kickoff 把目标和战略彻底对齐。
- **全球化不是扩张选项，是起点**：从第一天起就在多国建实体和合规团队，是 Deel 增长快的前提；「今天建公司就必须瞄准全球市场」。
- **最大的竞争对手是自己**：像 Bezos 一样持续创新、持续重塑自己，才能持续交付。

(function(){
  function fmt(s){
    if(!isFinite(s)||s<0) s=0;
    var m=Math.floor(s/60), x=Math.floor(s%60);
    return (m<10?'0':'')+m+':'+(x<10?'0':'')+x;
  }
  function wire(box){
    if(box.dataset.wired) return; box.dataset.wired='1';
    var a=box.querySelector('audio'), pb=box.querySelector('.pb'),
        bar=box.querySelector('.bar'), fill=box.querySelector('.bar > i'),
        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });

    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
