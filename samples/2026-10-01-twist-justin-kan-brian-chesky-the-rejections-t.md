# 回顾特辑：Justin Kan 的至暗时刻与 Chesky 的麦片融资

这一集是 This Week in Startups 的「回顾特辑」：主持人 [[Lon Harris|Lon Harris]] 请回前联合主持 [[Alex Wilhelm|Alex Wilhelm]],一起重看两期旧访谈——2019 年 2 月的第 900 期，嘉宾是 [[Justin Kan|Justin Kan]]([[Twitch|Twitch]] 的缔造者，当年把摄像机绑头上全天候直播自己人生的那个人，当时刚在法律科技公司 Atrium 完成 B 轮 6500 万美元融资)；以及 2023 年 5 月的第 1735 期，嘉宾是 [[Airbnb|Airbnb]] 联合创始人 Brian Chesky。

钩子是 [[Google|Google]] 的那记重拳：2010 年前后，Google 主动找上门说要收购 JustinTV,面试了他们整个团队之后，回头说——「你们的团队不够好，再见」。Justin 说这是他经历过最泄气的一击，而它恰恰成了 Twitch 诞生的导火索。

## Google 面试完整个团队，然后走了

僵尸创业公司的感觉，Justin 是这么形容的：25 个人，做了五年，增长不算太快，看不到退出的希望——「从来感觉不到有一个转折点，像是，天哪，我们搞明白了；也许有过那样的日子，但很快就又回到了基线」。

转机来得极其难堪。Google 来谈收购，理由是 YouTube 占据了整个互联网视频，直播只是其中一小块功能，「不如把这个功能买下来」。

Justin 团队让 Google 面试了全部员工，然后被嫌弃团队不够好、直接出局。他的教训说得斩钉截铁：永远、永远不要让收购方面试你的整个团队。

团队倒是接受得意外地好，大家想的是：反正卖不掉、又不增长，那就自己找出路。于是他们回到白板前开了那场著名的头脑风暴会——Twitch 由此开始成形。

## 3% 的内容，赌出十亿美元的 Twitch

那场会上，联合创始人 Emmett 提议：专注网站上的游戏内容——当时只占全部内容的 3%,每月几十万独立访客。他的论据不是数据，而是：「这是唯一一种我自己真正想看的内容。」星际争霸 2 刚发布，直播大多散落在 Ustream 等别的平台上，他相信围绕游戏能建出一个社区。

Alex 复盘时强调这有多反常规：今天任何一家风投支持的初创公司说「我们只服务 3% 的用户」，会被笑出会议室。在增长停滞期把稀缺资源押给一个小群体，当时看是大胆，回头看是天才——这一注最终迎来了被亚马逊收购的结局。

Lon 补充了时代背景：那个年代「人看别人打游戏取乐」对很多人是反直觉的，而且早期游戏发行商会用版权投诉打击直播者；如今除了任天堂，发行商们已经把主播当成命脉。Alex 由此延伸：规矩的「事实化」一直在发生——Uber 也是一样，小时候的教育是别上陌生人的车，一点点技术加一点时间，证明那完全错了。

> 【背景】正文提到的 Twitch 被收购一事：亚马逊于 2014 年以约 9.7 亿美元收购 Twitch（此为外部公开资料，原段音频中未提及具体金额）。

## Web 2.0 的热情，和「只要用户数」的荒诞

Justin 和主持人 Jason 回忆 Web 2.0 时代：Weblogs、Delicious、Flickr 都是小团队的热情项目，做它们不是因为赚钱，而是「看看我们能不能真的让这个网站在世界上存在」。Justin 说现在的旧金山缺了一点那种探索感——文化成熟了，人们是为了职业而来。Jason 回应说这是周期性的：互联网泡沫末期哈佛 MBA 们涌向 .com,一变难就跑回高盛——他把现在称为「旅游季」，而且正在旺季。

那个年代荒诞的另一面是「唯一指标就是用户数」。Alex 说他在 Mahalo 从没听过一次关于支出对比的对话，只有月活、只有增长，只要涨得够快投资人就给无限跑道。他举了 Cosmo.com:像 Grubhub 之前身，卖点是没最小订单量——你可以只点一个打火机和一块松饼，有人开车给你送来，因为他们只在乎「今天又多一个人用了」，好回去跟投资团队交代。

而这一切为什么一去不返？Alex 给了最干净的解释：Web 2.0 时代加一百万边际用户的成本只是带宽和 CPU 时间；Cosmo 那种涉足现实采购配送的生意，不收钱根本没法扩张；到了 [[AI|AI]] 时代更是如此——我们处在算力紧缺中，你消耗的每个 GPU 周期都有真实成本。

这正是如今公司变现更早更快的原因：不然你就成了又一个 YouTube,而且大概率找不到你的 Google。两人还顺带注意到，今天的聊天已经不同了：一个产品还在候补名单上，人们就已经在争论它的商业模式能不能成立(比如传闻中[[智能体|智能体]]产品靠交易抽成 2%-3%、酒店甚至愿意给 30% 分成)——以前这种讨论要等好几年。

## Chesky:15 万美元买 10%,没人要

回到 Airbnb。Brian Chesky 讲的被拒史：2008 年初，朋友介绍他们认识了十几二十位天使投资人，他们只想以 150 万美元投后估值融 15 万——花 15 万就能拿到 Airbnb 的 10%(Alex 当场算了笔账：今天那 10% 值 92.5 亿美元)。

结果多数人连邮件都不回；有人说「我们对旅游不感兴趣」；有位投资人的原话是：「我们喜欢一切，除了你和你的点子。」被嫌弃的点还包括创始团队里设计师太多——人们把设计师等同于不懂技术、不创造价值，而 Chesky 一直认为设计师出身恰恰是他们的秘诀，因为 Airbnb 从来不是一个纯技术问题。

接着是那个标志性的故事。YC 面试上，Paul Graham 的第一个问题是「真有人会这么做？

」第二个问题是「那他们有什么毛病？」面试中途 Paul 甚至劝他们干脆去做支付公司。

临走时，联合创始人 Joe 掏出一盒 Obama O's 麦片递过去——这是他们在 2008 年两党代表大会期间卖恶搞麦片盒赚的钱，靠寄给记者博报道卖出去。Paul 说了一句后来被无数人引用的话：「如果你们能说服人们花 40 美元买一盒 4 美元的麦片，那也许你们至少能说服一部分人住到彼此家里去。

」他们进了 YC。Paul 和 Jessica 后来说，投他们像投「蟑螂」——核冬天里唯一能活下来的东西。Alex 的解读是：韧性比上周的势头数据更重要，而这里展示的不只是韧性，是创造力和随机应变——同时搞定政治周期、新闻媒体和融资危机，还做得又酷又朋克。

## 创始人最重要的功课：了解自己，然后让路

Justin 给创业者的元层建议很朴素：最重要的了解自己——擅长什么就多做，不擅长的要么改进、要么委派。他观察到大多数创始人碰壁的方式是：事情开始见效了，却不肯从自己的路上让开——「因为我创造了这个产品而且它成功了，所以我所有的决定都是对的」(他提醒这里有很大的幸存者偏差)，于是对公司的所有其他部分事事插手、管得太细，或者自尊心强到不给招进来的人让路。

Alex 用亲身经历佐证：他服务过的一位好创始人、Ranker 的 Clark Benson,产品上直觉极准、没人质疑；但到了媒体和编辑领域就完全放手让团队实验——结果那块业务增长得非常好。Alex 还认为这段话是一种对「[[创始人模式|创始人模式]]」的隐性拒绝：一位把公司做到十亿美元退出的人，在谈共同担责、让聪明人经营自己的战场——和今天「一人高举火炬、深入细节」的风向在气质上很不一样。

## Chesky 在 2023 年的 AI 预言，如今看命中了几条

Chesky 谈 AI 的几段，被两位主持人评价为「有先见之明」。核心类比是相机：130 年前很少人会操作相机，拍照需要专家；编程本质上是用计算机的语言让它做事，而 AI 意味着你可以用你自己的语言让计算机做事——一旦不必学另一门语言，某种意义上人人都是程序员，就像人人都是摄影师。由此他预言「我们将生活在软件的丰裕之中」，AI 会创造数百万家初创公司、创业将迎来繁荣——就像 AWS 让创业者不必再自己机架堆叠服务器一样。

关于真假难辨，他的判断更冷：AI 的第一个词是「人工的」——在机器来消灭我们之前，最大的风险是它们变成我们，而我们无法分辨谁是机器。我们会生活在一个有人能听起来像你、举止像你的世界里，因此身份认证和「真实性」会成为人们想要的东西，而 Airbnb 的价值恰恰在物理世界。

Alex 评价：语音模型只要一小段音频就能模仿一个人完整的说话方式、假来电者已经能骗到家长——他说的都在成真。但他也提出一个质疑：2021、2022 年就有人说 AI 会带来线下真实体验的复兴，到 2026 年并没真发生；人们对 AI 产出确实更挑剔(只读 100% 人类写的 Substack、不要时间线上的垃圾内容)，但没人因此多去五场音乐会。

## AI 让你更忙，而不是失业

两位主持人对当下 AI 与就业的观察，可能是全集最实在的一段。共识是：至少到目前为止，AI 没让人失业，而是让每个人效率高了很多、因此忙了很多——「你完成的事情多了三倍，工作时间可能也多了一倍，但你没有被取代」。

Alex 用这个节目自己举例：以前他手工写节目 docket,要花三小时；现在由同事 Zack 维护一个 Claude 技能把选好的故事自动变成节目单，Zack 每天少花约一小时，但选故事、逐行质检、持续微调技能仍然是人的活儿，「两周之内我们不会靠迭代摆脱那份工作」。他自己的写作也一样：他在 Codex 里建了「结对编辑」技能，保留自己的语气和玩笑、只修语法——文字仍 100% 自己写，只是产能从一天一篇变成一天三篇长文。

他的结论：知识工作里高接触的劳动类别会被缓慢侵蚀，「只是不会像大家以为的那样在 18 个月内像惊雷一样发生」；长期净增工作、中期洗牌。Lon 补充了另一个微妙变化：非技术朋友现在用 Claude 就能给自己做小应用——我们没等到预期的创业大爆发，也许看到的是有工作的人在自己的角色里开「微型软件公司」，以及已经在做事的人(博主、宠物美容师)靠 AI 把手头的活做得强得多。

## 本集带走

- **永远别让收购方面试你的整个团队**：Google 面完 JustinTV 全员后说「团队不够好」转身走人；这场羞辱反而逼出了 Twitch。
- **数据小不等于赌注小**：Emmett 用「这是我自己唯一想看的内容」说服团队押注仅占 3% 的游戏内容——增长停滞期，直觉与用户同理心可以是最好的论据。
- **只看用户数的时代结束了**：Web 2.0 加用户几乎零边际成本，AI 时代每个 GPU 周期都烧真钱，所以如今商业模式在产品上线前就要被拷问。
- **融资融的是人不是点子**：Paul Graham 因为「能让人花 40 美元买 4 美元麦片」投了 Airbnb——韧性、创造力和会做生意，比势头数据更能预测成败。
- **创始人的第一课是了解自己，然后让路**：产品成功不等于事事正确(小心幸存者偏差)；擅长的事多做，不擅长的委派，别做团队的创意瓶颈。
- **AI 当下的现实：更多产出、更多工时**：它暂时不是取代你，而是把你的工作强度拧高一档；高接触知识工作会被缓慢侵蚀，不是 18 个月内的惊雷。
- **可上手的两招**：用智能体把数据变成「该做什么」的报告(下载你的 Analytics 直接丢给 Claude 问该发什么内容)；做几份 100% 人工撰写、AI 只做调研和琐碎活的通讯/文稿，守住语气与判断，放开产能。

    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
