# 把团队设计成「恐怖组织」：Snap 首位产品经理的反直觉产品课

这一集的主角是 [[Peter Sellis|Peter Sellis]]——他是 [[Snapchat|Snapchat]] 的第一位[[产品经理|产品经理]]，在那里干了七年，后来出任 [[Discord|Discord]] 的产品负责人，现在正处于两份工作之间，所以第一次愿意在没有公关团队约束的情况下上播客，敞开聊他真实的想法。他最反直觉的一个说法是：**他喜欢像设计恐怖组织那样设计团队**。这不是玩笑，背后有一套完整的组织哲学。

## 像恐怖组织一样设计团队

这个说法源于两个信念。第一，协作有隐藏成本：你永远不会听到任何高管说「停止协作」，而这恰恰是危险信号——协调成本保证了你的速度等于系统里最慢的那个节点。第二，在高增长公司里，产品经理做出的决定，应该是创始人一两年前才会亲自做的决定。

把暴力成分去掉，一个好的恐怖组织有两样东西：一是意识形态文化，每个人都明白自己为什么在做这件事——战略对整个团队几乎像一种宗教；二是极其清晰的组织结构，明确谁可以被[[信任建立|信任]]做哪种决策。两者结合，你不需要过度协作，却能达到协作才有的效果。

具体怎么做？当创始人仍在掌权时，产品负责人其实是创始人愿景的「容器」：把创始人的愿景吸收内化，然后凝练成可以反复使用的小短语——整个战略的「快捷方式」。他还研究过邪教组织，认为邪教更多围绕领导者个人，而恐怖组织围绕更高的理念，后者更值得借鉴——研究邪教时，学到它们「东窗事发之前的那一步」为止，能学到很多。

## 管理尖刺型人才：你管不了 Nikita Bier

Peter 在 Discord 收购了 Nikita Bier 的创业公司（Nikita 后来去了 X 做产品负责人）。他的结论是：「管理」这个词用得太宽松了——你没法管理 Nikita，只能控制或引导他。他把 Nikita 比作《飓风营救》里的 Liam Neeson：女儿被绑架时他有一套极罕见的技能、无比有用；但让他去买个菜，他只会把杂货店里所有人都杀掉。

由此引出的组织原则：**能吸纳「尖刺型人才」是组织的必备能力**，如果产品组织应付不了这种不完美朝九晚五的人，那是一种失败状态。他的管理风格参照公牛队和湖人队教练 Phil Jackson——把平常根本合不来的人融合成冠军球队。而对待难搞但有才华的 PM，他像对待出专辑的乐队：有时会出一张烂专辑，但如果仍相信他们是艺术家，就继续支持。

## 为什么大多数 PM 净负面：一道数学题

Peter 认为，在 ZIRP（零利率）时代，产品管理成了科技行业里非技术人才最赚钱的职业，但这个职业的分布天然有问题：真正当上 PM 的人都位于正态分布的右尾，切掉之后变成幂律分布——中位数远低于平均值。更糟的是双向抽水：最优秀的 PM 会退出体系去当创始人、当高管；而留在里面的人则想尽一切办法留下来。结果就是这个职业的中位数 PM 相当差。

有意思的旁证：优秀的工程师很少抱怨 PM——他们要么能让 PM 为其所用，要么根本不容忍差 PM；真正差的工程师也不抱怨，因为可以躲在 PM 的决策后面。**抱怨的只有中间那批人。**他还观察到，很多人说 PM 没用，只是因为他们从没和一个真正优秀的 PM 共事过。

## Snap 为什么没成为下一个 Facebook

[[Snap|Snap]] 有十亿月活，但没能做成想象中的庞然大物。Peter 从[[广告|广告]]变现角度给出三个结构性原因：**第一，用户太年轻。

**美国广告 CPN（单次触达成本）在 17 到 18 岁、18 到 21 岁之间存在一个「可疑的不连续性」——对未成年人的追踪和定向限制极其严苛，难以衡量就难以做效果广告。**第二，产品形态对广告不友好。

**所有非搜索类广告都依附于内容消费的屏幕，而 Snap 打开的是相机——拍完发给朋友的核心流程里没有任何放广告的合理位置。他承认自己最大的失败之一就是没能搞定相机变现。**第三，它的本质是即时通讯应用**，而全世界都没有针对通讯应用的好广告产品——包括那些常被引用的亚洲聊天应用，按每单位使用时间的收入算，变现都不怎么样。

但他也为 Snap 不服气：把它拆开看，这是 Z 世代的伯克希尔·哈撒韦——青少年第一的通讯应用（西方多国 21 岁以下渗透率 70% 到 100%）、他们最常用的相机、默认地图、最流行的占星应用。而且 Snap 起步比 Twitter、Reddit、Pinterest 都晚，广告收入到达四十亿的速度却比它们都快。

至于订阅产品 Snapchat+，他认为相当成功，唯一的遗憾是上线太晚——通讯工具的订阅渗透是缓慢线性增长的，用户要先在日常使用中获得价值才会付费。如果早四年上线，广告业务的扩张压力会更小，也许还能更有力地和 TikTok 竞争。

## AI 聊天广告：信任才是拍卖的货币

Peter 认同「广告是互联网的产品市场契合点」这一派。他看好 [[OpenAI|OpenAI]] 做广告，因为他们正在「速通」整套成熟的广告基础设施。核心的数学机制是改进版的 [[VCG|VCG]] 拍卖（[[Meta|Meta]] 2010 到 2020 年间最大的贡献之一）：不只让出价最高者赢，而是把广告对某个用户的自然价值计入出价——触达越不相关、越不想被打扰的人，广告主要付越多。

而聊天环境里，这套机制应该用「信任」替代「自然价值」：当用户问「我该买什么麦克风」，我该被广告主影响多少，本质上应该等于我愿意拿多少信任来交换。信任最大化很可能与用户留存相关，也与广告主价值相关。

反面教材是 Amazon 搜索：第一个真正结果之前有十六条广告，会潜移默化地侵蚀信任。他认为现在 PM 和设计师最酷的工作之一，就是 OpenAI 的广告形式设计——尤其是语音场景该长什么样，没人知道。

## 更多反直觉信条

**把最好的人用到极限，而不是提升普通人。**这反的不是直觉，是人性——看到有人溺水你会想救，而他做的完全相反：对持续做出好决策的人不断加码决策，直到看到他们开始做坏决策为止。

因为他没有很好的「帮助人提升」的机制，所以放手让不合格的人自己失败；同时恪守一条铁律：永远在公开场合为团队成员辩护。要注意的一点是：不关注某人，不等于他在失败。

**增长来自核心，而不是新市场。**网络效应业务的本质是内在地想增长。

最有效的做法是把 [[DAU-MAU|DAU/MAU]] 比率提高几个基点，而不是去拉一批新月活再赌留存——DAU/MAU 本质上就是次日留存。Snap 2018 年灾难性改版后 DAU 环比走平，之后聚焦 Android 性能优化，服务好已有的用户，带来了持续多年的「增长复兴」。

Discord 的例子更有说服力：所有人都说 Midjourney 建在 Discord 上是重大时刻，但从使用曲线上你根本挑不出 Midjourney 在哪；而在所有人都说「渗透率已经 100%」的多人游戏玩家身上做深，反而做出了疫情后最快的增长。他的总结是《发展受阻》式的：**「香蕉摊里永远有钱」**——回到核心用户，把产品对他们做到完美。额外的红利：游戏玩家是全世界最挑剔、最高 IQ 的用户群，为他们做到极致会带来极强的口碑外部性。

什么时候该扩展？两条路：一是把核心能力（Snap 的相机、Discord 的语音）套到其他人群上；二是留意用户「用脚投票」的意外用法——他们愿意绕弯路用你的产品做事，就是在告诉你该往哪扩展。

真正 Snapchat 式的做法是回溯投射（back casting）：完全抛开当下技术束缚去想未来。但极少有人有这种白纸式的创造力。最大的风险是 Nassim Taleb 的「感恩节火鸡」：一切都越来越好，直到一个 10 倍好的东西出现把你一夜归零。

防范火鸡困境的正面样本是 [[SpaceX|SpaceX]]：Falcon 9 是有史以来最伟大、成本效益最高的发射系统，每个国家都愿意拿 GDP 来换——而他们宣布让它退役，全力转向 Starship。这是科尔蒂斯级的「烧掉船只」。

Peter 认为这是 SpaceX 最被低估的能力：Elon 建立了一种彻底拥抱「打破创新者窘境」的文化——完全愿意建造和自己竞争的东西，让自己最伟大的作品过时。而且 SpaceX 和 Tesla 公开发布十年计划并说到做到，「作为产品负责人，我渴望达到那种自信的程度」。

## 品味就是说「不」的肌肉

Peter 在 Snap 学到的最重要一课：他见过 Evan 亲自否决掉的点子，比他见过的几乎所有其他消费级创业公司上线的产品都要好。他把优秀的产品领导者比作博物馆策展人：产品在任何时候呈现的东西只是全部藏品的一小部分——**如果一个博物馆把全部藏品都挂在墙上，这个策展人什么都没做。**

怎么在面试中检验[[品味|品味]]？问对方：你做过但从未发布的东西是什么——不是测试数据不好而砍掉的，而是捧在手里觉得「世界还没准备好」的那种。

有大量高质量 shelved 点子的人，才真正锻炼过「说不」这块极少数可以锻炼的品味肌肉。这在 AI 时代尤其关键：AI 极不擅长做减法，它只会往产品里加东西——砍掉东西的责任落在了产品团队头上。

## 优秀 PM 身体的三对狼

Peter 给出的优秀 PM 画像，是三组必须共存的矛盾：**自信近乎傲慢 × 认真的谦逊**——坚信方向正确，同时能把功劳精确给到那个最后一刻改方案的设计师；**极度流程驱动 × 对模糊性超级适应**——「我给所有事都准备了清单，但必须推倒重来时也完全没问题」；**长期思考 × 近乎烦人的行动偏好**——清楚世界两年后该长什么样，同时每天醒来公司就跟着醒。面试时能通过故事同时展示这三对狼的候选人，对他有致命吸引力。

最后是他的「重辣」观点，一个他说取决于雇主都不敢说的话：要为某些人群做出真正出色的消费级产品，产品和设计师身上存在某些**无法习得的特质**——性别、种族、成长背景、社会经济出身。这不是「做给谁就要招谁」，而是因为消费级产品本质上都在冲击马斯洛需求层次的某些部分，有些人的成长经历让他们天然更懂那些需求。他承认这个观点在很多情况下甚至不可执行——这正是它辣的地方。

## 本集带走

- **团队组织的两条腿**：把战略凝练成可反复传播的短语（意识形态）+ 明确到人的决策责任结构，就能用更少的协作达到协作的效果。
- **评估 PM 别只看人，要看「人 + 环境」**：这个职业的分布决定了中位数 PM 很差，优秀者会流向创始人和高管岗位。
- **增长先抠 DAU/MAU 几个基点**，别急着拉新；DAU/MAU 就是次日留存的另一种形式。
- **把广告做成「长期贪婪」**：明天的广告收入因果地取决于今天为广告主创造的 ROI——哪怕牺牲短期收入。
- **用「核心产品价值」统一使命与指标**：像「与你最好的朋友分享瞬间最快的方式」这样能拆解成具体指标的短语，能让新数据科学家快速上岗。
- **面试问「你做过但没发布什么」**，这是检验品味最有效的问题之一。

    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
