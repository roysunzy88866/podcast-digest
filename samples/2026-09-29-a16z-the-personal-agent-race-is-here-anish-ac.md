# 个人 AI 智能体爆发前夜：从订机票到替你砍价的隐形助手

<div class="pd-byl"><b>David Pawlan</b> · AssistantBench 创建者 · 2026-09-29</div>

这一集是 a16z 的 Anish Charya 与 [[AssistantBench|AssistantBench]] 创建者 David Pollitt 的对谈。David 搭了一个叫 Assistant Benchmark 的网站，用同样的提示词（比如「帮我订一张去芝加哥的航班」「在我位置五个街区内找素食餐厅」）去测市面上所有个人 AI 助手，在 16 个维度上比较一次性指令下的真实结果——它真的办成了吗？

会不会追问细节？上线才 16 天，网站已有超过 10 万访客，几乎每个这个领域的创始人都来找过他。

钩子是他对 Meta 刚发布的 [[Muse|Muse]] 硬件（Muse charm）的判断：那东西有摄像头和多个麦克风，他怀疑它根本不是为了赢硬件，而是 Meta 在现实世界里收数据，喂给 Zuckerberg 想把真实世界地图化的元宇宙。

## 四周之内，赛道炸了

11 月下旬 [[OpenClaw|OpenClaw]] 发布席卷世界；最近 [[Instinct|Instinct]] 引爆科技推特，然后像多米诺骨牌——GrokBot、Muse，以及一堆长尾产品如 Caddy、Ollie、Pally。据他统计，各个类别加起来目前有 122 个产品，仅通用类就有 64 个。

格局上分两类：一边是面向消费者的通用[[智能体|智能体]]（Instinct、Muse、Caddy、Ollie 等），另一边是 B2B 工作流型助手，更像「行政助理」路线。

## 大家真正用它干什么

从他把 1200 多名助手爱好者拉的七八个群聊看，讨论度最高的使用场景排序是：**第一是日常行政杂务**——清收件箱、填表格这些真正烦人的事；**第二是智能体编排**——怎么让智能体互相协作、在手机上发消息就能改设计文件；**第三是开发**；**第四才是旅行**。旅行虽然传播度第一（「它帮我值机了！」），但人们不是天天旅行，它更像吸睛的噱头。

金融是他最看好的[[主动性|主动性]]场景，但不是因为「赚钱」——「如果你能让智能体帮你赚十亿美元，所有对冲基金早就做了」。真正会爆发的是**省钱型工作流**：翻一年收据提交 HSA 报销；他自己每次订完机票，票价一跌就让助手去找航空公司要旅行代金；朋友把 GrokBot 接到家里洒水器并连上天气系统，水费降了 50%。Anish 补了一个关键的用户心理：没人想听「省钱」，但这些东西体感上是「免费的钱」——这才是强大的获客钩子。

这里回应了 Ben Thompson「消费者要花时间、不要省时间」的论调：David 同意普通人不在乎效率提高 10%，但美国消费者生活里有大量重行政的部分（罚单、保险、报销），正是智能体的突破口。

## 最好的员工是隐形的

这一集的核心主张：**赢家会是最主动、最隐形的那一个**。「你雇一个助手，就是为了让它是隐形的——你雇一个人不是因为你喜欢管理他。」最好的员工只管把事办完，然后汇报一句「这是我做好的」。

但主动性有一条微妙的界线，David 的划分是：**需要你这边改变行动的事，必须先征得同意**（比如智能体发现你的保险太贵、想帮你换——这直接影响你）；**不需要你行动、纯帮你省时间省钱的，可以直接做**（起草好邮件、拿到航班积分）。这条线一旦越界一次，你会立刻失去用户的全部信任。Anish 内部开玩笑说，离智能体发消息说「我看你对她没那么上心，就替你把她分了」只有几天之遥——但反过来，如果没人发推晒「我的智能体主动做了这个」，那说明产品在这个方向上推得还不够狠。

由此他还延伸：个性不是护城河——你说一句「别这样回我」，它存进记忆就改了，太容易配置。真正可防御的是主动性本身。

## 用什么界面交互

界面之争基本是两种形态：[[iMessage|iMessage]] 或独立应用。David 觉得 iMessage 在手机上是「特权位置」，更私人、不像额外附加的工作流；也见过第三种——初创公司 Sky 用 iPhone 小组件当界面。形态可能按代际甚至性别分化：Z 世代爱发短信，千禧一代爱应用界面；他妻子做梦想板、旅行看视觉，偏爱可视化界面，他自己只在乎「怎么从 A 到 B」。

硬件方面他反对「每个做硬件的人都觉得自己那件是终极形态」，觉得会像首饰一样按个人偏好分化（项链派 vs 耳环派），但他看好有东西全天候伴你身边、捕捉一天里所有承诺和约定这个方向；他还认为纯音频眼镜可能是黑马——既有科技连接性、又没有脸上挂摄像头的社交尴尬。

[[语音|语音]]是他本集的「第二个魔法时刻」：[[ChatGPT|ChatGPT]] Voice 接入 Gmail 和日历后，他骑车上班的 30 分钟里，动嘴就把邮件分类、贴标签、回信、发日历邀请全办完，到工位时收件箱清零。他的洞察是：助手在你双手最忙的时候最有用——园艺、做饭、骑车，而不是坐在沙发上时。

## 群聊里的智能体：闭嘴的那种最讨喜

把智能体拉进群聊总感觉有侵入性。David 见过三种做法：直接进群当伙伴；Instinct 的智能体网络（智能体在幕后代表你谈，再向你汇报）；以及他觉得最有意思的 Doc——智能体进群但**完全沉默**，只记笔记，有行动项时单独私信提醒那个人，群成员可以去看它记的文档。 again，隐形智能体：干着所有人想要的行政活，不打扰任何人。

Anish 引用 Nir from Obo 的判断：模型在编码这类可验证领域进步是指数级的，但在文笔和「 bedside manner」上可能已停滞甚至变差——所以今天的模型很难真正增强群体的社交连接，智能体该做的是实用主义的事（他在收藏家群聊里试过给各自的藏品做编目）。

## OpenClaw 的教训与「狭义创业公司」

对当前产品的判断相当犀利：现在市面上的消费级智能体，本质就是预配置好的 OpenClaw 复刻——能力上没什么是 OpenClaw 或 Hermes 做不到的，差别只是你不用自己配环境、不会每隔七小时弹一次报错。方向上他会继续看到两件事：主动性深化，以及超专业化。

超专业化连着 Anish 的「[[狭义创业公司|狭义创业公司]]（narrow startups）」论点：现在可以给极少数人做极其有用、极其昂贵的软件——已有人们为软件付每月 200 到 300 美元的先例，所以可以做出几万用户、年经常性收入 1000 亿美元的生意，这在过去不存在。差异化来自品味加专有知识：就像有人雇信奉特定分娩流派的导乐，你会雇信奉某套思想流派的智能体；也可能有一个专为纽约市打造的、品味难以复制的礼宾型智能体。

顺带聊了词：助手（assistant）是低一级的形态，只能做你指派的事；智能体（agent）有主观能动性，能让好事直接在世界上发生——可以被想象成社交圈里的同侪。

## 当智能体开始和智能体做生意

往后看五年，最有想象空间的是智能体对智能体（agent-to-agent）交互：会有智能体专属的邮箱、电话号码；当服务从「人对人预订」变成「智能体从智能体那里预订」，整个服务业被重新定义；然后必然像互联网之后有网络安全一样，催生智能体安全这个新产业。

商业上本周已经分了阵营：**[[Shopify|Shopify]] 拥抱 Muse，[[Amazon|Amazon]] 屏蔽 Muse**。David 的解释是商业模式不同——Shopify 专注让商业民主化，智能体帮每个人卖得更多，天大利好；而 Amazon 收入靠广告，当人的眼球被移除，整套广告结构就失去意义。

Amazon 大概是正确地下注：不能被去中介化，否则丢的不只是广告收入，还有冲动型购物。Anish 则提出一个反直觉追问：智能体本身会不会也是冲动型购物者？

主动性意味着它爱做「令人愉悦的猜测」，而有什么比惊喜和礼物更愉悦？所以营销、广告不会消失，只是需要被改造——智能体不是其主人的完美理性映射，会以全新的方式非理性。

餐厅预订是供给受限的典型：Rezzy 已经开始关停用浏览器自动化抢位的账户。当人人都有智能体、人人都能同一秒抢位，要么权力回到餐厅（按忠诚度、平均消费挑选客人），要么进入智能体之间的竞价战。需求受限的场景则相反：买家聚合发出需求，商家竞标谁能以最好体验、最低价格满足——供给端的聚合加拍卖，历史上从未真正存在过。

[[推荐引擎|推荐引擎]]是另一个悬而未决的问题：你说「给我买白袜子」，市面上有两万种白袜子，智能体并不知道你偏好哪种。Muse 靠 Instagram 和 Facebook 的数据可能有先发优势；但 Anish 想象的是长尾的「不期而遇」——你的智能体回来告诉你，Etsy 上内布拉斯加有位老奶奶织的白袜子棒极了，要等三周，你愿意吗？甚至智能体直接去联系老奶奶的智能体谈这单生意——一个比今天动态得多、频率高得多的二级经济。

## 钱的问题：免费巨头压顶，长尾怎么活

他统计过的 122 个产品里，他亲手测了 26 个；65 个收费，其中 35 个完全付费、30 个免费增值，真正免费的只有 13 个。但占主导的 Muse 和 Instinct 都是免费的——长尾初创公司怎么收费？

Anish 给出账：以真正雄心勃勃的方式做这件事，估算成本约每个用户每天 20 美元，对初创公司一年就是数亿美元。可以押注的趋势是浏览器使用成本会通缩式暴跌（token 价格已在大幅下跌）；但他不喜欢「客户补贴」当价值主张，他真正想看到的是**那个每月 1000 美元、用户兴奋到愿意掏钱的智能体**——同时吃到极端的产品市场契合和成本下降两重红利。

## 本集带走

- **主动性的红线划分**：需要你改变行动的事（换保险、下单）先征得同意；纯省钱省时间的事（找航班差价、起草邮件）直接做。越界一次，用户信任归零。
- **最好的助手是隐形的**：用户不要 10% 的效率提升，要的是「拍张照，罚单我自己去交」级别的完全托管——你雇人不是为了享受管理他。
- **频次决定定位**：旅行这类低频高价值行为大概率是通用智能体的「连接器」而非独立赢家；日常行政杂务才是最高频的真实需求。
- **省钱场景的正确话术是「免费的钱」**：翻收据报 HSA、追机票差价、按天气浇水省一半水费——没人想听省钱，但人人都爱意外到账。
- **界面按人群分化**：iMessage 的特权位置（已连接你、非附加工作流）vs 独立应用；语音在双手忙碌时最强；硬件形态会像首饰一样按个人偏好分化。
- **Amazon 屏蔽 Muse、Shopify 拥抱**：广告驱动的平台怕失去眼球和冲动消费，赋能中小卖家的平台则因智能体进一步民主化而受益——商业模式决定站队。
- **智能体商业的两个新命题**：推荐引擎（两万种白袜子你到底要哪种）和智能体间交易基础设施（智能体邮箱、电话号码、竞价与安全）。
- **商业模式的赌注**：浏览器自动化成本正快速通缩，但赢家不该靠补贴——要做出贵到每月 1000 美元用户仍愿付费的智能体。

<script>
(function(){
  function fmt(s){
    if(!isFinite(s)||s<0) s=0;
    var m=Math.floor(s/60), x=Math.floor(s%60);
    return (m<10?'0':'')+m+':'+(x<10?'0':'')+x;
  }
  function wire(box){
    if(box.dataset.wired) return; box.dataset.wired='1';
    var a=box.querySelector('audio'), pb=box.querySelector('.pb'),
        bar=box.querySelector('.bar'), fill=box.querySelector('.bar > i'),
        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
