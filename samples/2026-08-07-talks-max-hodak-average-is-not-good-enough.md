# Speed 就是护城河：Science CEO 谈深科技公司的基础设施

这一集是 [[Max Hodak|Max Hodak]] 在 Startup School 的演讲加问答。他是 [[Science|Science]] 公司的 CEO，Science 的主要产品是一种视网膜假体——植入视网膜下方的芯片，患者戴的眼镜上有摄像头和激光投影仪，红外线投影到芯片上产生电场刺激视网膜，绕过坏死的视杆和视锥细胞，为失明患者恢复视力。一位患者用这个设备读完了一本 300 页的小说，还把书寄给了公司；产品已完成三次临床试验，去年有患者登上《时代》封面。

但这场演讲不讲这个产品，讲的是一套听起来无聊、却决定成败的东西：[[AI 基础设施|基础设施]]。他引用毕加索的名言开场——艺术评论家聚在一起谈形式和意义，艺术家聚在一起谈去哪买便宜的松节油；也就是「业余者谈战略，专业人士谈后勤」。

他的核心主张是：**[[迭代|迭代速度]]决定成败，而速度由基础设施决定**。深科技公司很少死于技术行不通，更多死于组织大到几百人、几万平米设施后，没有系统把它管起来，战略接不上执行。

## 买东西：第 17 个员工怎么下单

第一个反复出现的普遍问题是采购。创始人自己刷卡买东西当然容易，问题是「你的第 17 名员工怎么买东西？

」给所有人发信用卡、逐笔审批，你会卡在「3000 美元的电源要不要等拍卖会半价买」这种取舍上——但每周工资烧 10 万美元，为半价等一周早把省的钱亏光了。逐笔审批是错误的审查场合，支出审查必须更早、以预算的形式进行。

于是你建采购系统，高薪员工开始整天折腾 B2B 企业级 SaaS:跟供应商开户、处理保险认证文书、生成报价单再生成采购订单再生成发票，一个电源两周才到。他的结论是：采购就是一个需要主动管理、盯指标的「活的有机体」。

从学术界转来的人常问「为什么有人专职买东西」——确实需要。Science 以快速著称，他说这主要不是因为他们更聪明，而是这类基础设施就是速度的来源。

控制了总支出后，真正的问题是**归因**：批量买进的气体、树脂、培养基分摊到无数实验里，没人知道一次实验、一轮晶圆迭代到底花多少钱。结果「实验是免费的，它花的是培养基，培养基来自冰箱」——你既没法给自制产品定价，也算不清 runway。

Science 为此自建了叫 [[Helix|Helix]] 的内部软件，把公司里几乎每件事都变成软件里的一个按钮，实验室每一步都进数据库，才能算出这轮晶圆协议一次迭代花 4 万美元。他算了笔账：A 轮融 2000 万美元，20 人团队人力一年约 300 万，2 万平方英尺场地一年约 100 万，真正的自由研究预算是每年 300 万、撑三四年——「花得比你想象的快得多，而你的团队刚见到此生最大的一笔钱，会以为 3000 美元的电源是免费的。」

## 招聘：全公司投票，迅速出结果

第二个普遍问题是[[招人|招聘]]。最好的公司来自「圈子」(scene),最好的招聘来自你自己的关系网、以及孕育出这家公司的那个圈子——那些已经说你的语言的人。但这样的人永远不够填满整个公司，所以你需要一个**定义清晰、被虔诚执行的流程**——没有唯一正确答案，但错误答案是公司没有固定的招聘仪式。

Science 的流程是四步：初步投票、电话初筛、作业、完整面试。申请进来后，系统自动挑出七八位背景相似的在职员工投票，把初始筛选分散到全公司——如果你做的事情够酷，几年后漏斗顶端会泛滥成灾，任何一小群人当瓶颈都会卡死整个组织，投票机制同时也是对全团队判断力做平均的方式。

实际数据：17% 的申请进入电话初筛，初筛按全公司统一标准找三样东西——判断力、能力强度、主观能动性；一半进入作业；到面试环节转化率必须保持在至少 25% 到 offer,否则 onsite 会浪费太多时间。他认为这四步是做出完整决定的最少信息集，没有更少的步骤。

作业环节的关键是「抗 AI」:他们最喜欢的作业不会饱和、天花板极高、天然可打分成两三个能画在图上的数字——有人真正打败了帕累托前沿一眼可见，用什么 AI 模型都无所谓。他举了 Anthropic 的例子:GPU kernel 优化任务，一段时间里门槛是 Sonnet 的性能，超过它就拿面试。

## Eigenreviews:把绩效评估变成 PageRank

怎么知道你招得好不好？公司成败是反馈，但那是极长、极糟糕的损失函数。

管理者要设计「合成梯度」提前拿到信号。常规的年度 360 评估在他看来是有破坏性的流程，只会强化你已知但没行动的问题。

他开发并用了一套六七年的替代方案：每四到六周，随机 ping 一位员工，问唯一一个问题——「知道这个人的表现之后，你今天还会为他的录用再投一次票吗？」然后基于所有反馈在公司内构建一个图，基本直觉是：如果其他人都给你打了高分，你的投票权重就该更高。

这本质上是 Google PageRank 的「特征向量中心性」，他们叫它 **[[eigenreviews|eigenreviews]]**。它把判断分布到全公司、以约一个月的延迟连续更新，还附带了反作弊技巧——跑一千次迭代、每次随机删掉一些边(类似机器学习里的 Dropout),如果分数分布出现额外的峰，就是存在投票小圈子的线索。他确信这基本就是做绩效评估的正确方式，欢迎写信找他要具体技巧文档。

## 行动产生信息

收束到哲学层面：创业没有通用算法，是一长连串的判断取舍，而 CEO 无法把判断委托给别人——像考试抄邻座，成绩只会被拉向班级平均，而成功的公司是例外，你的判断必须差异化地好，哪怕在认知上完全孤身一人。到公司四五年、数亿美元押在一个只有你能做的决定上时，你会四处找建议却发现「没有人可以问」——那一刻你必须清楚自己判断的边界，然后坚定地押下去。

好消息是行动空间总是比看起来大，很难真正陷入僵局。「[[行动产生信息|行动产生信息]]」这句话比听起来深刻——每当陷入僵局，就必须开始投射行动、产生熵。他见过公司卡在很深的局部极小值，移走一个个人能力很强但与公司当下不匹配的人，反而解开了阻塞。

## 问答精华

**读博还是创业？** 如果你的领域只存在于基础研究，读博合理；但一个领域真正开始运转时，工业界能调动的资源和速度远超学界——最好的计算机科学家已经从 CMU 和哈佛移到了 Google 和 OpenAI,最好的火箭科学家在 SpaceX。

他更推荐先去一家高绩效、文化值得敬重的公司，和判断力被验证出色的人共事——这是口传心授的强化学习，很多人低估了它对创业者教育的价值。他自己的 [[Neuralink|Neuralink]] 经历就是如此：遇到两个方案拿不准，那位 CEO 看一眼说「肯定是 B」,问题就再也没复发。

**什么算卓越能力的证据？** 任何你能具体指出来、把这个人跟他高中同学区分开的东西；最好的证据是在清晰可见的竞技比赛中获胜——象棋特级大师、Design Build Fly、Formula SAE。一批硅谷深科技公司就是大学 Formula SAE 优胜者建起来的。

**AI 取代了什么？** 他们发现 AI 是团队的乘数而非替代品。影响最大的三块：写代码(他自己最近六个月几乎没看过源码了)；法规——质量体系是典型的重型官僚主义，要识别所有适用标准、建合规证据表，过去要几个月，AI 让查标准和生成证据表都变快了，他认为「AI 与监管的结合比人们想象的更匹配，法规是用血写成的，大体是好主意，只是人类做起来太难」。

**为什么自建平台而不是买？** 没有哪家公司爱自己的 ERP 系统；YC、Facebook、SpaceX/Tesla 的 Warp Speed 都是围绕为自己量身定制的软件运转的。

以前软件太贵只能买，现在 vibe coding 让自建变得合理——这是[[智能体|智能体]]带来的改变。他们把 Greenhouse 换成自建工具后，才能做商用软件做不到的精细投票机制。

**长周期技术要融多少钱？** 找出下一个关键价值拐点需要哪些实验、算出价格，然后**融两倍的钱**——有些想法值得用 5000 万或 0 美元去验证，但不值得 500 万，因为根本跑不完实验，只会得到模棱两可的结果。同时要比你以为的更早追求收入：公司像在缓慢死于一种「金钱癌症」，每隔几年靠融资打到缓解期又复发——有了收入，你会按长期路线图被估值，而不是按死亡概率被估值。

**[[BCI|BCI]] 的未来？** 他说近期 BCI 与其说是 AI 故事，不如说是「长寿故事」：大脑是让你成为你的东西，是原则上唯一无法移植的器官，而它通常不是最先坏掉的。

神经工程的效应量是医学里见不到的——打开脑深部刺激器，帕金森患者 10 秒内从端不起水杯到能写连笔字。剩下的最大工程难题是低功耗电子和「封装」(欧洲同行叫 tropicalization):身体里没有真正惰性的表面，连骨骼都在被重塑，你需要一种能长期抵抗身体攻击的材料。

## 本集带走

- **速度决定成败，基础设施决定速度**：采购、招聘、支出、绩效这些「后勤」与你对技术本身的理解同等重要；每周学一件事的公司，对每月学一件事的竞争对手构成永久压制。
- **支出审查前置成预算，不逐笔审批**：高薪员工为半价电源等一周，亏的比省的多；给他们预算，让他们在真实资源内自己做取舍。
- **[[归因|成本归因]]到实验级**：没人知道一次实验多少钱，实验就会被当成免费的；把每一步进数据库，才算得出成本、定价和 runway。
- **招聘流程要固定要快**：全公司分摊投票避免漏斗瓶颈，统一标准筛判断力/能力/能动性，作业设计成抗 AI、天然可打分，面试到 offer 转化至少 25%。
- **用「还会再投一次票吗」替代年度评估**：每 4-6 周随机互评 + PageRank 式加权，连续、无偏、自带小圈子检测。
- **融资按实验定价再翻倍**：跑到下一个价值拐点所需的实验成本 × 2,宁可融大也不留模棱两可；并尽早追求收入，摆脱「按死亡概率被估值」。

  //    pathname → spaNavigated 永远置不了 true。window 上用「未设置才记」守卫,只在**第一次**记真·落地路径,
  //    重执行/换页都存活;__pdSpa 一旦置 true 就 sticky。referrer 用整 origin 比对(new URL),防

<script>
(function(){
  function fmt(s){
    if(!isFinite(s)||s<0) s=0;
    var m=Math.floor(s/60), x=Math.floor(s%60);
    return (m<10?'0':'')+m+':'+(x<10?'0':'')+x;
  }
  function wire(box){
    if(box.dataset.wired) return; box.dataset.wired='1';
    var a=box.querySelector('audio'), pb=box.querySelector('.pb'),
        bar=box.querySelector('.bar'), fill=box.querySelector('.bar > i'),
        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
