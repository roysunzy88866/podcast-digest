# Bending Spoons：被硅谷误读的「收购机器」，人均 400 万美元收入怎么来的

收购 [[Airtable|Airtable]] 的消息一出来，硅谷有点炸锅——一家意大利公司，把硅谷曾经的明星创业公司买走了。说这话的人是 [[Luca Ferrari|Luca Ferrari]]，[[Bending Spoons|Bending Spoons]] 的联合创始人兼 CEO，这家总部在米兰的公司过去十年悄悄买下了 [[Evernote|Evernote]]、[[AOL|AOL]]、Vimeo、Meetup、StreamYard 等一串数字业务，现在又被视为「在吃掉硅谷」。Ferrari 自己不觉得在吃掉谁，但这期访谈里他拆解的那套打法，和硅谷的直觉几乎处处相反。

## 他们不是 PE，也不是「坟墓收购者」

外界最常见的两个标签，Ferrari 都否了。第一，他们不是[[私募股权|私募股权]]（PE）：PE 募资买公司、平均持有五年再卖掉；Bending Spoons 从不卖掉有实质规模的业务，「打算永远拥有并运营」。

第二个区别是深度：PE 通常换管理层、调定价，很少重建底层技术；而 Bending Spoons 会重建代码库的很大一部分、重构云基础设施、重新发明商业化定价、从头重做营销。第三个区别是整合：所有业务都架在一个共享平台上，核心团队集中管理、在各业务间灵活流动——而这恰恰是 PE 结构上做不到的，因为整合过的业务根本没法再单独卖掉。

至于「专收老破旧、坟墓公司」的说法，他甩出一个数字：五亿月活跃用户。「如果每个月五亿人在用还叫坟墓，那行，就这么叫吧。

」他举 AOL 为例：成立约 40 年，至今仍是西方世界第五大邮箱提供商，数千万人的主力邮箱，而过去十年那些被媒体热捧的邮箱创业公司，加起来的体量可能还不到 AOL 的 5%。「我们不太在乎酷不酷」——不酷反而意味着收购价格更实惠。

## 那套「操作系统」才是护城河

Bending Spoons 的核心资产，是一个十年攒出来的、由超过 50 项专有技术组成的操作系统，覆盖运营数字业务几乎所需的一切：数据存储与处理、A/B 测试、支付管理、招聘、凭证管理、AI 模型[[编排|编排]]等等。买下公司就像「把它们安装到这个共享操作系统上」。

为什么自建而不采购？Ferrari 给了三个理由：一、他们需要的复杂度超出市面工具——工具商面向大众企业市场优化，真要造他们需要的东西，市场只有一两个客户，没人会造；二、自建工具原生互相集成，每个工具能与其他工具对话，外采则供应商一改你就得全改；三、省钱——他估计每年至少省一亿美元成本。而这套东西对任何一家被收购的独立公司来说都不经济，研发投入的回报周期太长；Bending Spoons 把投资摊销到整个组合上，这是独立公司拿不到的规模优势。

还有一个内置飞轮：所有业务都用所有工具，谁发现 bug 或需求缺口，就像内部开源社区一样改进它，改进随后惠及所有其他业务——组合越大，工具进化越快。

## 平台怎么建：让「战壕里的人」从零到一

这套系统不是规划出来的，是迭代出来的。Ferrari 和联合创始人们在 2010 到 2013 年间经历过一次失败的创业，最大的教训是「思想上保持谦逊」：有愿景，但假设自己很可能是错的。

落到技术上就是两条原则。其一，小步快跑、高度谦逊：从不先做多年期投资再验证，而是先建小块、交给各业务试用，看采用反馈再决定加码还是推翻。

其二，绝不派平台团队从零造新东西——「让需要它的人来构建它」。他们会挑一家对某个工具特别重要的业务，由它自己动手建，成功后再移交给平台团队打磨和扩展。道理很朴素：经历过问题痛苦的人，才更可能造出真正有用的解法，而不是对着想象中的问题沉迷工程挑战。

## 收购标准与 AI 公司的淘金热

选标的的关键标准只有两条。第一，业务轨迹必须可预测——他们买入是为了永久持有，需要能描绘出至少未来五年的曲线，萎缩的业务也可以买，但必须知道它萎缩多快，这是不可协商的。第二，必须确信自己能大幅增值——提收入、降成本，否则无法既给出对卖方有吸引力的价格、又为股东拿到高回报。

对当下这波 AI 应用公司，他们暂时一家都不收。不是不看好 AI——Ferrari 自称在运营中部署 AI 的激进程度大概处于第 99 百分位——而是这是一场淘金热：有人凭一个想法就以十亿美元估值融资，大量公司只是虚浮的泡沫，而增长 100% 的公司你无法判断三年后是 100% 还是 12%，这会改变一切；况且估值往往高得有道理，他们竞争不过、也拿不到好回报。等市场成熟些再看。

值得注意的是他对硅谷模式的公道话：依赖早期充裕资本的模式整体上极其有效，过去几十年硅谷的总体投资回报非常出色；2021 年估值确实失衡，但如果有人犯错，那是投资者，不是公司——以能拿到的最好估值融资是对股东负责任的做法。Airtable 的 Howie 和团队其实非常自律：没多融、保持盈利、几乎没烧钱，13 亿美元企业价值减去账上现金，投资者拿回了本金还多一点，退出估值与公开市场同等质量 SaaS 一致。一家公司能以超十亿美元退出，本身就是千分之一的稀罕事，人们忘了这有多难。

## Alt Spooner：住在 Slack 里的「另一个你」

AI 落地上最能说明他们风格的是今年内部开发的 [[Alt Spooner|Alt Spooner]]：一个住在 Slack 里的[[智能体|智能体]]，你在 Slack 上像对同事一样跟它说话，它可以有名字和头像，并且自动拥有与你完全相同的全平台访问权限——你能访问的代码库、客户支持工具，它都能。

两个真实例子。Ferrari 前一晚要看 StreamYard 上某些 A/B 测试结果，往常得请数据科学家提取数据、花几个小时，这次他跟自己的 Alt Spooner 聊了几句，五分钟后拿到了带重点标注图表的分析。另一个发生在 Evernote：总经理发现自己遇到一个 bug，让智能体去客服平台查这是普遍问题还是只她一人报告，再进代码库定位根因、写修复代码、通知工程负责人审查并推上生产——她花了大约三分钟下指令，工程负责人花了一两个小时审代码，bug 当天修复；这事的常规流程大概要几周。

更关键的是底下的编排系统：每次下达任务，算法综合考虑质量、效率和成本，自动选最合适的模型或模型组合。99% 的请求跑的是他们自托管的[[开放权重模型|开放权重模型]]，基本免费；前沿模型只通过 API 处理约 1% 的最复杂任务，或者自动充当「资深工程师」审查便宜模型产出的工作——不行就给指点、让便宜模型去修。

结果是 token 成本低到在他们的规模下可以忽略，并且不对任何 AI 供应商产生依赖。Ferrari 的判断很直接：把钥匙交给一家大厂、买它更贵的产品，能让你更快显得「已启用 AI」，但效果差得多、贵上几个数量级。靠着这类技术，他们的生产力轻松提升了两到三倍。

这里有个顺带的设计逻辑：被收购业务的工程师如果做腻了 Evernote 的笔记功能，只需举手说「我耗尽了创造力」，就可以转到平台团队造内部技术、或去 AOL 改进邮件体验——多业务轮岗本身就是顶级人才留任的理由。这也解释了他们的招聘漏斗：2025 年收到 80 万份申请，录用不到 300 人；核心团队去年不想要的人员流失率仅 0.6%，而他了解到多数科技公司 5% 就算相当不错。

## 极致理性：一台逼近真相的学习机器

把这些串起来的底层文化，Ferrari 总结为两条。一是「[[极致所有权|极致主人翁精神]]」：宁要稍微不那么聪明但真正在乎的人，也不要不在乎的聪明人。

二是高度科学化的工作方式：第一性原理、讲逻辑、大量实验——仅去年一年就跑了超过 3000 个覆盖各产品的、超定量有记录的实验。他对「追求真相」有一套近乎哲学的表述：如果你对业务和市场的真相有完美理解，你几乎注定成功，因为你不会设不可能的目标；难就难在真相难知，变量太多、环境变化太快。

所以要用科学方法探测世界、修正现实模型、再相应执行。而大多数人并不寻求真相，只寻求快乐和舒适，只想确认自己是对的——仅仅是逼近真相这个心态，就能让你脱颖而出。

## 为什么「没人做有意义的安全工作」

谈到 AI 风险，Ferrari 的自况是「一半满怀热情，一半吓得要死」：它可能是人类有史以来以数量级计的最大恩惠，也可能消灭我们。他指出的两点比较少有人谈。

一是 AI 像核武器但可能更糟——核武器很难在不杀死自己的前提下造成不可逆的全人类级破坏，而 AI 可以在给你自己牟利的同时对所有人造成巨大伤害，因为它「精确得多」。二是我们不知道 AI 有多聪明，而且它越聪明我们知道得越少：智力本就难客观度量，一个实体越聪明就越容易隐藏自己的能力；再加上 AI 被编程得天生谦虚、从不自夸，只会展示你要求展示的东西，我们可能一直在系统性低估它们——而逼近危险阈值时，哪怕轻微的低估都可能是灾难性的。最近发生的网络安全事件里模型展现的横向思维与协作能力就震惊了大多数研究者，「我们并没有忽视大量根本尚未被探测过的能力」——这话是反讽：我们正在忽视。

至于「人们没问过的问题」，他的答案是：不是没人问该做什么，而是没人问「为什么什么都没发生」——实验室在抢市场领导者地位否则估值跌 90%，政府层面他只见到了对行业危害极大、却没触及任何真实存亡威胁的欧盟 AI 法案。找到这个无能的根因，才可能做点有用的事。

## 本集带走

- **买来是为了永远运营，不是转卖**：可预测至少五年的业务轨迹是不可协商的标准；萎缩的业务可以买，但必须知道它萎缩多快。
- **平台让收购产生复利**：50+ 项自研工具原生集成、全组合共用，一处改进惠及所有业务；独立公司自建不经济，这就是他们能开出高价还赚高回报的来源。
- **新工具由「战壕里的人」从零建**：谁痛谁动手，成功后移交平台团队打磨；平台团队只负责优化存量，不负责从零到一。
- **AI 落地靠编排而不是买最贵的**：99% 请求用自托管开放权重模型，前沿模型只兜底最难的 1% 和当「审查员」，token 成本几乎可忽略，且不锁定任何供应商。
- **提高人均产出的结构杠杆**：精简小团队、人才高密度、去繁文缛节；不在意单一业务增长 15% 还是 5%，只要求增长是可盈利的，多余现金拿去更高回报的收购——人均收入从两三年前的约 100 万美元涨到了 400 万。
- **对 AI 风险更该问的问题**：不是「我们该做什么」，而是「为什么什么都没发生」——找到阻碍修复方案落地的根因，才有可能真正行动。

    if(box.dataset.wired) return; box.dataset.wired='1';
    var a=box.querySelector('audio'), pb=box.querySelector('.pb'),
        bar=box.querySelector('.bar'), fill=box.querySelector('.bar > i'),
        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
