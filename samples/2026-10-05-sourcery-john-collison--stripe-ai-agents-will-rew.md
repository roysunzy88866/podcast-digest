这一集是 [[Stripe|Stripe]] 联合创始人 John Carlson(注:应为 [[John Collison|John Collison]],Stripe 两位创始兄弟中的弟弟,公司今年是第 17 个年头)在一场以浏览器技术为主题的大会上与主持人 [[Molly O'Shea|Molly O'Shea]] 的对谈。

Stripe 在 2025 年处理了 1.9 万亿美元交易,同比增长 34%——而 Collison 的核心判断是:[[智能体商务|智能体商务]]不是给现有电商加个功能,而是「一次彻底的重构」,连 Stripe 自己最擅长的事都一夜之间变了。

> 【背景】John Collison 是 Stripe 的联合创始人兼总裁,与哥哥 Patrick Collison 于 2010 年共同创立这家在线支付公司。转写稿将其姓名听写为 "John Carlson"。

## 智能体为什么终于能替你干活了

填网页表单「对任何人来说都不是一项有增值的活动,没有人会选择在空闲时间里填写网页表单」。

[[智能体|智能体]](能自主替你执行任务的 AI)之所以现在真正开始奏效,Collison 认为有两个条件:一是给个人智能体足够多的算力,让它真的能去做事;二是「[[计算机使用|计算机使用]]」(computer use,让 AI 像人一样操作电脑界面)成熟到了可用的程度。

他把后者称为「现实世界的终极向后兼容层」——你想让车管所(DMV)给驾照续办系统加一个 [[MCP|MCP]] 接口(AI 调用外部工具的协议)?

「我打赌我们得等上好几年。但这不要紧,因为计算机使用解决了这个问题。」

## 「彻底重构」到底重构什么

第一阶变化:大量商务将由个人智能体代为完成。

第二阶变化更有意思——AI 做产品调研时,「经常真的会浮现出你没听说过的利基品牌」。

他的判断是:**AI 发现正在成为商务的新聚合点**,头部商家格局会洗牌,产品真的好、可被发现的商家会在排名中迅速窜升。

他给出的类比是上一代社交广告:Facebook 和 Instagram 的定向投放催生了 Wish.com、Teespring 乃至后续一批同样原生成长于平台的新一代公司,而握有同样工具的大型连锁零售商因为「不那么原生」被甩开。

AI 电商大概率重演:第一阶让买东西更方便,第二阶重塑商家格局,偏向最会采用它的人。

> 【背景】这类「原生成长于社交广告平台」的后续公司,典型例子如 Temu、Shein(此为编者补充背景,原文未点名)。

## 安全:攻防天平正在向攻击方倾斜

AI 是防御者和攻击者都能用的新技术,他借了汽车诞生的老类比:「银行劫匪是最早采用汽车来实施银行抢劫的」,很快警察也不得不用车才能追上——猫鼠博弈永不过去。

他的直白判断是:「未来五年,你会看到比过去五年更多的安全泄露事件」,没有第二种可能,因为「攻防均衡」只是「假设一头球形奶牛」式的理论,现实中大量组织采用新能力的速度会太慢。

对在座的初创公司这是个好消息:它们更容易用上最新模型,技术栈更小、更可控、更同质化;而跑着五十年历史、靠收购堆出来、还在用不再受支持的 Windows 版本的老技术栈,处境就很不妙。

## Stripe 把 1 月 1 日定为「奇点纪元」

Stripe 内部半开玩笑地把 2026 年 1 月 1 日称为「[[奇点|奇点]]的第一天」——就像 Unix 纪元是 1970 年 1 月 1 日。

选这个日期并非全然巧合:去年年末正是很多人看到编程模型突飞猛进的「天哪」时刻。

所谓[[递归自我改进|递归自我提升]](用 AI 来让 AI 变得更好)不再是理论,实验室正在用 AI 能力加速模型开发——「我们现在是数学大战,还有对立的数学派系,这完全不是我 2026 年宾果卡上会有的东西」。

Stripe 看到的早期经济指标相当乐观:「随取随用的智能」变便宜后,新公司创建率是「近期记忆中最高的」。

他们不以悲观或担忧的方式看待奇点,「只是我们正处于 AI 起飞的这一刻,你应该享受它」。

至于该不该害怕:「人们应该担心**具体的**担忧——比如确保你的[[网络安全|网络安全]]真的靠得住——而不是普遍怀有一种不祥的、压抑的、沉重的预感。」

## 连 Stripe 自己都一夜换棋局

最能说明「格局在变」的例子是 Stripe 自己:十几年打磨开发者体验——API 文档的细节、版本迁移的顺畅度——「几乎是一夜之间,实际上已经没有人再手工集成 Stripe API 了。

他们把[[编码智能体|编码智能体]]派去干这件事」。

而这是另一门手艺:「开发者的人体工学和 AI 的人体工学不一样」,很多让开发者舒心的设计对 AI 根本不重要,反而 AI 很容易集成错版本的 API。

所以 Stripe 不得不「彻底改变内部所擅长的东西」——每个人的棋盘都被晃了一下,现在你面对的是一个新棋局。

## 收购在拼一张什么图

近期的收购([[Bridge|Bridge]]、[[Privy|Privy]] 做加密支付,[[Metronome|Metronome]] 做[[基于使用量的计费|用量计费]],[[OpenRouter|OpenRouter]] 做 AI 模型路由)各有一条逻辑:

- **加密**:Bridge 和 Privy 团队是 crypto-native 的,这种特质 Stripe 自己很难快速长出来,他们给公司文化注入了很多。
- **用量计费**:AI 让每家公司都有了[[推理|推理]]成本(调用大模型的花费),所以如今很少有产品没有按用量计费的成分——你订阅了 ChatGPT 或 Claude,用超了套餐就得买 credits。「由于底层的成本结构,如今每家做 AI 产品的公司都需要基于用量的计费。」
- **模型路由**:OpenRouter 的赌注是——一家企业内部会同时用不止一个模型,而且选择会变:高价值用户路由到前沿模型,低价值用户路由到便宜模型,取决于用户生命周期价值。「据我们所知,在帮助企业实际使用多个模型这件事上,他们走得最靠前。」

至于自建还是收购,他的答案朴实:「买那些买下来比自建更划算的公司,所有的品味和细微差别都在这里。」

一块全新的能力(比如 token 路由)Stripe 能学会,但会花长得多的时间;而市场演进极快时,等你内部做出来就过时了。

## 内部最兴奋的变革:人人自建软件

给 AI 接上内部数据并不容易——隐私护栏、访问控制(HR 数据库不该人人可看)、正确性都很复杂。

但一旦做到,变化是遍地开花:销售团队不再用公司统一给的工具,而是**自己搭应用**来为一个客户拼装个性化推介;法务团队有人自建智能体,摄取全世界可能涉及 Stripe 的新法规——毕竟「印度刚发布一个 600 页的新法律,你读了吗?

抱歉,没有,我在读芬兰那个 600 页的」。

「人们谈论[[个性化软件|个性化软件]]已经几十年了,而此刻准入门槛终于降得足够低,我们正在看到大量的个性化软件。」

他也因此对 [[Browserbase|BrowserBase]] 这类公司特别兴奋: transformers → 大模型 → 加上 RL,AI 的进步是一连串离散跃升,「好的计算机使用将被视为下一个跃升之一,因为它是世界其余部分的后向兼容层——你不必等 DMV 去添加一个 MCP server」。

## 他怎么保持信息灵通

不装:「我认识那种说自己睡前读 10 篇 AI 论文的人,我也不确定他们是不是真读。」

他的方式:一,vibe code(用自然语言让 AI 生成程序)自己想要用的应用,而且真能获得实实在在的效用;二,持续和 Stripe 平台上增长最快的公司聊天——「看冰球要滑向哪里,而不是公司当前的规模」,而增长最快的公司必然是 AI 或围绕 AI 的。

## 该问而没人问的问题

很多网站在做[[机器人检测|机器人检测]]和拦截,这可以理解,但「如今几乎全都是机器人了」。

等好机器人坏机器人蜂拥而至,新的甄别机制是什么?

「在那个世界里,机器人检测应该长什么样——有好机器人,也有坏机器人,你需要能在两者之间做甄别——而新均衡会是什么样,我们只是不知道。」

## 17 年,他学到了什么

- **没有捷径**:Stripe 从来没有在 South by Southwest 爆红的时刻,「每一年都比前一年规模更大,一年接着一年,你最终就能达到 1.9 万亿美元」——但从来没有「天哪这东西真管用」的感觉。
- **新产品一开始都是玩具**:他们很少启动「当时就觉得是公司未来」的产品,只是启动一个能给客户创造价值的不错的东西,然后坚持。
- **坚持不懈被低估**:NVIDIA 早早开始造 GPU,造更好的 GPU,加上了 CUDA——「有很多时期,NVIDIA 都远不如今天这么火热」。

  > 【背景】CUDA 是 NVIDIA 于 2006 年推出的并行计算平台。
- **打无限游戏**:声誉很重要,认真做一个好的交易对手。
- **用户优先**:Stripe 运营原则第一条。「公司很容易迷失,开始想『我们该进什么市场』『下一个营收池是什么』——那是一种内部的、以公司为导向的思维方式。」

## 本集带走

- **计算机使用是现实世界的向后兼容层**:不用等每个机构都提供 API,让智能体直接操作现有界面就能干活,这是下一波 AI 应用的地基。
- **AI 发现是新聚合点**:产品真的好且可被发现的商家会快速上位,长尾品牌迎来红利窗口,现有聚合平台要重新回答自己的位置。
- **开发者体验 ≠ AI 体验**:如果你的产品靠开发者手动集成,现在的主要「用户」可能是编码智能体——文档、版本、易错点都要按 AI 的人体工学重做。
- **AI 产品离不开用量计费**:推理成本决定了订阅制必须叠加按用量/超额计费。
- **担心具体的担忧,而不是弥漫性的恐惧**:把精力放在能验证的事情上(比如网络安全),初创公司小而同质的技术栈反而是攻防优势。
- **个性化软件的门槛已经塌了**:销售、法务都能自建工具——最好的内部 AI 落地,不是给员工做统一应用,而是让员工自己会搭。===金句===

  //    pathname → spaNavigated 永远置不了 true。window 上用「未设置才记」守卫,只在**第一次**记真·落地路径,
  //    重执行/换页都存活;__pdSpa 一旦置 true 就 sticky。referrer 用整 origin 比对(new URL),防
  //    「本站origin.evil.com」前缀欺骗(GLM 011[2])。
  if (window.__pdLanding == null) window.__pdLanding = location.pathname; // == null 兼捕未设置态,且不把该字面量带进页面(既有「页面无脏词」闸门)
  function pdSameOrigin(u){ try { return new URL(u).origin === location.origin; } catch (e) { return false; } }
  function direct(){
    if (location.pathname !== window.__pdLanding) window.__pdSpa = true; // 跳到别的页 = 站内导航(sticky)
    var fromSite = pdSameOrigin(document.referrer || '') || window.__pdSpa === true;
    document.body.classList.toggle('pd-direct', !fromSite);
  }

<script>
(function(){
  function fmt(s){
    if(!isFinite(s)||s<0) s=0;
    var m=Math.floor(s/60), x=Math.floor(s%60);
    return (m<10?'0':'')+m+':'+(x<10?'0':'')+x;
  }
  function wire(box){
    if(box.dataset.wired) return; box.dataset.wired='1';
    var a=box.querySelector('audio'), pb=box.querySelector('.pb'),
        bar=box.querySelector('.bar'), fill=box.querySelector('.bar > i'),
        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
