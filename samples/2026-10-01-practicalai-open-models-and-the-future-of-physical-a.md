## 物理 AI 里的开放模型,比云端更刚需

物理 AI 涵盖汽车、工厂自动化、机器人(还有农业、建筑等)这些垂直领域,共同点是 AI 部署在会扰动物理世界的设备上,产出是摸得着的东西。Ming-Yu 认为最令人兴奋的形态是[[人形机器人|人形机器人]]——它们需要一台强大的计算机来处理视觉输入、理解指令、对未完成的任务自我纠正,而这是 NVIDIA 眼里的巨大商业机会。<button class="pd-ts" data-t="09:55" data-who="Ming-Yu Liu" data-en="As you mesh these things together, what does that look like to you now? 开放模型在物理世界里甚至更关键,原因很具体:**每台机器人看世界的方式都不一样。**有的机器人两只眼,有的摄像头装在夹爪上;自动驾驶车有的 11 个摄像头、有的 7 个,有的带 LiDAR(激光雷达)。

## 上设备做推理,和云端完全是两套逻辑

Ming-Yu 给习惯了云和 API 的从业者列了几条物理 AI 独有的约束。第一,机器人要实时反应,处理必须在现场完成。

第二,很多任务是「批大小为 1」的[[推理|推理]]——不像 API 服务可以把成千上万用户的请求聚合起来填满 GPU 算力,单台设备没有可聚合的调用,所以 [[LLM|LLM]] 那套基于自回归 transformer(逐个生成 token、受内存带宽限制)的架构在设备上跑不满算力,别的架构可能更高效。第三,还有实时和安全约束。结论:应用不同,催生的架构和芯片就不同,核心问题是怎么把每一瓦电用得更值。<button class="pd-ts" data-t="17:41" data-who="Ming-Yu Liu" data-en="Okay, so basically it's been the difference in physical as compared to the digital AI that people are very familiar with. ## 世界模型:Cosmos 的核心赌注

Cosmos(Cosmos 是「世界」的词根)在做的事叫[[世界模型|世界模型]]。它和 LLM 是两条学习路径:LLM 从人类以语言书写的知识里学表征,优化生成文字;世界模型从对世界的感官观测——相机捕捉的不同角度、物理如何随时间演化的动态——里学表征,人们相信建模这些信号能隐式编码世界的物理规律。一旦物理规律成了可建模的东西,就能做[[模拟|模拟]];再把世界表征和语言表征接起来,模型就能解释「为什么发生了这件事」。<button class="pd-ts" data-t="20:00" data-who="Ming-Yu Liu" data-en="But, help help those who maybe maybe imagine someone who has just used LLMs or maybe that's their only perception of models. Help connect what a world model is and why it might be necessary in this world of physical AI." aria-label="回原文"></button>

Cosmos 把世界模型拆成两个用途,并在最新的 Cosmos 3 里把两者融合:

- **世界模拟**:输入当前观测 + 动作序列(动作有时用文字描述就行),输出未来——以视频形式呈现将要发生的画面。
- **世界理解**:输入视频和文本,输出文字解释。比如机械臂没完成任务,模型能告诉你「有个障碍物挡住了路径」。这一侧更像多模态 LLM。

## 世界模型到底怎么用:自动驾驶的例子

最实用的部分是它如何改变开发迭代方式。训练一个自动驾驶[[策略模型|策略模型]],你会产出很多 checkpoint(训练过程中的模型版本),怎么知道 A 比 B 好?

过去的做法是:车队 + 司机,把每个新策略部署到真车上路测试。这显然不可扩展,直接限制了你能迭代多少次。

有了世界模型,让策略和世界模型交互就行:策略说「左转」,世界模型生成「左转会看到什么」。在模拟里快速筛掉大多数假设,只把剩下几个真正有价值的拿去做真车测试。

Ming-Yu 点破:「在技术领域,最重要的事情是你能做多快的迭代。」<button class="pd-ts" data-t="29:50" data-who="Ming-Yu Liu" data-en="It's a good question. So in COSMO, we build this foundation model and try to learn a good world representation. Right? And this model can be used in many different ways. From the simulation perspective." aria-label="回原文"></button> <button class="pd-ts" data-t="31:02" data-who="Ming-Yu Liu" data-en="Right? When you're still left, what you're gonna see? You're still right, what you're gonna see? Right? And from this simulation, you can verify the accuracy of a checkpoint." aria-label="回原文"></button>

世界模型的表征还能当策略模型的骨干(backbone):世界模型生成的像素空间演化,与完成操作任务所需的控制信号有强相关性,这个相关性在数据有限时是很好的正则化(一种防止模型过拟合、提升泛化的约束手段),帮你训出更好的策略模型。<button class="pd-ts" data-t="31:26" data-who="Ming-Yu Liu" data-en="It can help you quickly narrow down a couple hypotheses you have. It help you to get this iteration faster, now we know in technology, the most important thing is how far you can do iteration. Right? Then you can develop better policy for your self driving car." aria-label="回原文"></button>

## NVIDIA 的「开放」到底开放到什么程度

Ming-Yu 专门澄清了 NVIDIA 语境下「开放模型」的含义,远不止开放权重:

- **训练框架**:拿开放模型 + 你自己的数据,训练出更适合你用例的版本;
- **开源数据**:他们自建的数据集也开放,想自研模型的人可以直接用;
- **开发者博客 + 示例 recipe/cookbook**(放在 GitHub):沉淀合作伙伴的成功用例,照着学怎么用开放模型;

<script>
(function(){
  function fmt(s){
    if(!isFinite(s)||s<0) s=0;
    var m=Math.floor(s/60), x=Math.floor(s%60);
    return (m<10?'0':'')+m+':'+(x<10?'0':'')+x;
  }
  function wire(box){
    if(box.dataset.wired) return; box.dataset.wired='1';
    var a=box.querySelector('audio'), pb=box.querySelector('.pb'),
        bar=box.querySelector('.bar'), fill=box.querySelector('.bar > i'),
        tm=box.querySelector('.tm'), t2=box.querySelector('.t2');
    if(!a||!pb||!bar||!fill||!tm) return;
    var total=0;
    function paint(){
      var cur=a.currentTime||0;
      fill.style.width=(total?(cur/total*100):0)+'%';
      tm.textContent=fmt(cur)+(total?' / '+fmt(total):'');
    }
    a.addEventListener('loadedmetadata',function(){
      total=a.duration||0;
      if(total&&t2) t2.textContent=Math.round(total/60)+' 分钟 · AI 合成朗读';
      paint();
    });
    a.addEventListener('timeupdate',paint);
    a.addEventListener('play',function(){ pb.textContent='❚❚'; pb.setAttribute('aria-label','暂停'); });
    a.addEventListener('pause',function(){ pb.textContent='▶'; pb.setAttribute('aria-label','播放'); });
    a.addEventListener('ended',function(){ pb.textContent='▶'; });
    pb.addEventListener('click',function(){ if(a.paused) a.play(); else a.pause(); });
    function seek(ev){
      if(!total) return;
      if(ev.clientX==null) return;
      var r=bar.getBoundingClientRect();
      var x=Math.min(Math.max(ev.clientX-r.left,0),r.width);
      a.currentTime=(x/r.width)*total;
      paint();
    }
    bar.addEventListener('pointerdown',function(ev){
      seek(ev);
      function mv(e){ seek(e); }
      function up(){ document.removeEventListener('pointermove',mv); document.removeEventListener('pointerup',up); }
      document.addEventListener('pointermove',mv); document.addEventListener('pointerup',up);
    });
    a.addEventListener('error',function(){
      box.classList.add('pd-play-dead');
      box.textContent='本集中文精华音频还没生成好,稍后再来听。';
    });
  }
  function all(){ document.querySelectorAll('.pd-play').forEach(wire); }
  document.addEventListener('nav', all);
  if(document.readyState==='loading') document.addEventListener('DOMContentLoaded', all); else all();
})();
</script>
