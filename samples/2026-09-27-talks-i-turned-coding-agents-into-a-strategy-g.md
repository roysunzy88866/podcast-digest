# 你才是瓶颈:像打游戏一样指挥智能体大军

<div class="pd-byl"><b>Ido Salomon</b> · AgentCraft 创造者 · 2026-10-01</div>

这一集是一个现场演示演讲,主角是 [[Ido Salomon|Ido Salomon]]——[[AgentCraft|AgentCraft]](一个游戏化的[[智能体|智能体]][[编排器|编排器]])的创造者,他还做过 MCPUI(后来演变成 MCP Apps),也在 MCP 指导委员会。他抛出的核心主张很扎眼:智能体已经够强了,现在真正限制产能的,是我们人类自己——因为我们没法同时又引导、又指挥、又审查 20 个智能体而不累垮。

而解决方案所需的技能,其实我们早就会了:玩《魔兽争霸》《模拟人生》这类游戏时,不就是在监督一堆四处跑的单位吗?这套直觉和检查智能体没多大区别。所以他把这个概念「推向极端」,做出了 AgentCraft。

## 第一步:可见性——先看得见

要用好智能体,第一个门槛是理解它们在干什么。AgentCraft 里每个智能体是地图上的一个单位,可以是 Claude Code、Codex、OpenCode 等任何你已有的智能体,也可以直接在工具里新生成;侧边栏列出每个智能体的任务、最后动作、当前动作,让你一眼判断谁需要关注。更进一步,它把文件系统投影到地图上:文件变成房间,你能直观看到「这个智能体正在处理这个目录/文件」,还能基于这些信息做热力图。

反应机制也借鉴了 RTS 游戏(即时战略游戏):按一下空格键,直接跳到最近一个需要你关注的事项——回答问题、批准计划,像《文明》里点空格跳到告警点一样。

## 第二步:自主性——别事事盯着

[[可见性|可见性]]还不够,以「它现在在用哪个文件、哪个工具」的粒度持续盯着,非常累人。问题有两个:一是脑子里装不下那么多状态,没法同时想 20 件事;二是就算让智能体通读代码库、自动生成任务、你点一下「接受任务」就有智能体去做——接下来就是 20 件事同时进行,每一件都要你「看管(babysit)」,彻底精疲力竭。

于是他把审查也交出去:让智能体当编排器,把目标拆解后放进隔离的本地容器里自主运行(现在这套思路叫「软件工厂」);再加上现在流行的循环(loop)玩法——比如让它扫描 Twitter 找想做的点子、或扫描你的 GitHub,后台自动做出功能,前期几乎不用操心。

剩下的问题是怎么高效审查堆积的结果。他的答案是「[[审查工具包|审查工具包]]」:一份改动里,你可以逐文件看,也可以直接看「可视化证据」——改动前后的视频和截图,快速判断要哪个;甚至并行跑几个实例,挑出最好的实现。

## 第三步:协作——别一个人干活

可见性加[[自主性|自主性]]之后仍然累,而且「整天只跟智能体说话相当孤独」。他给 AgentCraft 加了多人[[协作|协作]]:可以建「作战室」,完全本地运行但支持隧道让远程的人加入。

演示里他批准妻子(团队的产品设计师)进房,她做设计,他作为工程师直接在地图上看到设计、接着往下实现——她还在继续工作。也就是说,团队获得了一个共享工作区:可以用 Git,但不再被 Git 绑死。

房间里有聊天和公告板,人和人、智能体和智能体彼此知晓对方在做什么,协作比平时紧密得多。这套东西也能在移动端、Telegram 上用。

## 意外收获:天花板之上,还有地板

反馈里最有意思的不是高级用户能干更多活了,而是一群原本与智能体毫无关系的人进来了:有孩子用它编排智能体,还有个因为沉迷《星际争霸》从大学辍学的人,现在能用它做很有生产力的事。这让他意识到:抬高天花板之外,还要降低地板——要把世界上大约 90% 的人带进这个未来,而不让他们累垮。

他的新实验(暂名 [[loopers|loopers]],还非常早期)放弃了魔兽式的复杂界面:不追求「它正在改哪个文件」的粒度,而是做成手游级别的体验——有几个你会不断回访的项目,靠循环等更自主的机制,达到「我发提示词、我拿结果」的最简交互,过程想看可以看,不看也行。他强调这只是其中一种可视化,人和人不一样:对一个人简单神奇的东西,对另一个人可能很难;所以他在探索让这套体验更可定制,理解「你作为一个人」到底需要什么才能愿意用这些工具。

## 收尾与现状

他的结论:我们确实是瓶颈,但让我们不再是瓶颈的技能早已在我们身上——不必一直是瓶颈。AgentCraft 已经上线,npx install 即可用;loopers 还在实验阶段,他在收集用户兴趣来决定方向。

## 本集带走

- **人是瓶颈,不是模型**:开 25 个智能体容易,难的是引导、指挥、审查它们不把自己累垮——规模化智能体的真正约束是人类注意力。
- **可见性先做两层**:列表式的状态面板(谁在干什么、最后动作)+ 把文件系统投影成地图/房间/热力图,空间直觉比读列表快。
- **借游戏的反应机制**:像 RTS 的空格键一样,一键跳到最近需要关注的事项,批准/回答不迷路。
- **审查要降粒度**:别逐文件硬啃,直接看改动的截图/视频证据,并行跑几个实现挑最好的。
- **别单干**:共享工作区 + 公告板让设计师、工程师和各智能体互相看见、接力推进,不必被 Git 工作流绑死。
- **天花板之外还有地板**:对高手给粒度和复杂度,对新手给「发提示词、收结果」的手游级循环体验——90% 的人靠后者才能进来。
