你在大会、旅行、聚会上录了一堆视频，却几乎从没发到网上——因为视频剪辑又繁琐又基本靠手工，像一门艺术而不是能自动化的活。这场演讲的主角 Kate 是 [[Reelful|Reelful]] 的创始人兼 CEO,她要做的事就是把这个活交给[[智能体|智能体]]：你把照片和视频丢进来，加一句指令(或什么都不说)，智能体自己理解素材、挑出最好的片段、加字幕、配音乐、配音、做 B-roll(补充画面素材)，最后给你一条可以直接发社交媒体的成片 <button class="pd-ts" data-t="01:18" data-who="嘉宾" data-en="And that's why we're building RLFL and we're trying to tackle agentic video editing problem from the agentic standpoint. I'm Kate, I'm founder and CEO at RLFL. But let's first talk about what agentic video editing is." aria-label="回原文"></button>。

## 什么智能体视频剪辑，以及它难在哪

用户侧的体验很简单：放入媒体文件，加上下文——可以是描述素材里发生了什么，也可以是指令，比如「加字幕、加音乐、加配音」。然后智能体自己完成剩下的一切 <button class="pd-ts" data-t="01:28" data-who="嘉宾" data-en="But let's first talk about what agentic video editing is. So as a user, you just drop in your media photos and videos and provide some context. It can be the context what happened in this media files or it can be some directions." aria-label="回原文"></button>。再举个例子：你录了一段对着镜头说话的视频，里面满是停顿和废镜头，智能体自己判断该删什么、怎么接，交付一条可直接分享的片段 <button class="pd-ts" data-t="02:12" data-who="嘉宾" data-en="And yeah, so basically that's agentic video editing, so agent does everything by itself. Or another example, you recorded a speak-to-camera video and you have a lot of pauses, unsuccessful shots, and you expect an agent to figure it out to remove unsuccessful shots, remove pauses, and give you a ready-to-share clip." aria-label="回原文"></button>。

从基础设施角度看，智能体视频编辑器和智能体应用构建器(比如帮你写应用的那种)结构非常相似：都有提示词入口(视频编辑器是「媒体 + 提示词」)，后端都会启动一台远程机器——[[沙箱|沙箱]]，里面有一个带着工具和技能的智能体在干活；应用构建器操作的是代码库，视频编辑器操作的是视频合成；前者交付应用预览，后者交付渲染好的视频 <button class="pd-ts" data-t="03:00" data-who="嘉宾" data-en="And since we're at AI Engineering Conference, I wanted to talk a little bit about infrastructure. And from the infrastructure standpoint, Argentic Video Editor is very similar to Argentic App Builder." aria-label="回原文"></button>。

但 Reelful 特意选择了更难的那条路：**只剪辑真实素材，不大量生成内容**。生成等于给智能体一张空白画布，想做什么做什么；而剪辑要求智能体自己判断哪些片段最好、省略什么、怎么组织，素材还可能凌乱不完整，却仍要交付专业水准的成果——理想情况下，观众根本分辨不出是 AI 剪的还是人剪的 <button class="pd-ts" data-t="04:12" data-who="嘉宾" data-en="And, but yes, from infrastructural standpoint, it's pretty similar, but there are a couple of differences. And this is actually the most interesting to me, generating versus editing." aria-label="回原文"></button>。

## 流水线五步：从素材到成片

Reelful 的完整流程是这样的 <button class="pd-ts" data-t="05:35" data-who="嘉宾" data-en="So we start, as I already mentioned, with your media plus a prompt, some directions like how you want it to be edited, and we need to get a polished clip. So let's go through it step by step." aria-label="回原文"></button>:

**第一步，媒体理解**。智能体要先看懂每段视频和照片里发生了什么，并对着镜头说话的视频做语音转录。

**第二步，创意方案**。在真正动手剪之前，先生成一份创意方案给用户确认——喜欢就批准，想改就改，也可以要求重新生成。这一步把「品味」的最终决定权留给用户。

**第三步，启动沙箱执行**。用户批准后，智能体在沙箱里开工，自带两类东西。

一是**技能**：比如剪辑规则(怎么挑最佳片段)、字体搭配(什么场景用什么字体)、怎么生成 B-roll——Kate 强调，这正是品味和手艺真正沉淀的地方 <button class="pd-ts" data-t="06:31" data-who="嘉宾" data-en="So the agent comes with the skills, and in our case, in the case of video editing, Our skills are, for example, cut rules, how, for example, how to select the best moments, also font pairs, which fonts are more suitable for this use case, which are not, for example, how to generate B-rolls, and this is where taste and craft live, actually." aria-label="回原文"></button>。二是**子流程**：智能体可以按需启动生成匹配这段构图的音乐、生成配音、添加音效，甚至把你提供的照片做成动态的，让画面更有动感 <button class="pd-ts" data-t="06:51" data-who="嘉宾" data-en="Our skills are, for example, cut rules, how, for example, how to select the best moments, also font pairs, which fonts are more suitable for this use case, which are not, for example, how to generate B-rolls, and this is where taste and craft live, actually." aria-label="回原文"></button>。

**第四步，[[Remotion|Remotion]] 合成**。Remotion 是一个开源框架，用 React 代码来写视频——一个文件按顺序定义所有素材、轨道和衔接方式。选它的理由很直接：智能体非常擅长写代码，所以让它们用写代码的方式造视频 <button class="pd-ts" data-t="07:21" data-who="嘉宾" data-en="What's Remotion? Remotion is a framework, open source framework to create videos as code, as React code. So basically it's just like a file with the order with all your assets and tracks and how they're following each other." aria-label="回原文"></button>。

**第五步，验证层**。智能体会犯错，所以 Reelful 专门开发了验证层，检查整个合成是否干净、定义良好、能不能全部渲染出来；发现问题就打回去让智能体迭代修改 <button class="pd-ts" data-t="07:55" data-who="嘉宾" data-en="And then the last thing is the verification layer. Of course, agent can make mistakes, and that's why we developed this verification layer to make sure that all the composition is clean, is well-defined, everything will be rendered, and if there are some problems, then the agent will reiterate on the composition." aria-label="回原文"></button>。

## 把复杂工作流卖给大众消费者的三招

这套流水线很复杂，但 Reelful 的目标是让用户对它一无所知也能用。具体做了三件事 <button class="pd-ts" data-t="08:40" data-who="嘉宾" data-en="And this is even maybe a bigger problem, how to deliver this complex agentic workflow to mass consumer. And this is how we're tackling that at Reelful. So we decided to go mobile first so that users can edit videos while driving, walking, or maybe lifting weights." aria-label="回原文"></button>:

**移动优先**——让用户能在开车、走路甚至举铁时剪视频；**方向性模板**——Kate 承认用提示词描述剪辑需求本身就难，所以提供「对着镜头说话」「加 B-roll」「加配音」这类模板，用户选一个、拖入素材即可，完全不用写提示词也能出片；**传统编辑器兜底**——用户先让智能体生成视频，想微调(删掉一秒、改字幕里一个词)时，可以进一个熟悉形态的编辑器手动改。

演示的例子是她自己拍的：一条关于 Cursor 创作者晚宴的视频，全程只用智能体组装，没用任何常规视频编辑器，她已经直接发上了社交媒体 <button class="pd-ts" data-t="10:52" data-who="嘉宾" data-en="One of the highlights. So yeah, basically, all these videos, they were assembled only using agent, no regular video editor. And I already posting them on social media." aria-label="回原文"></button>。Reelful 还处于早期，刚发布了第二个版本的 beta,并拿到了 A16Z speedrun 的投资 <button class="pd-ts" data-t="11:46" data-who="嘉宾" data-en="And also some exciting news. We recently got funded by A16Z speedrun. So I'm very excited to continue working." aria-label="回原文"></button>。

## 本集带走

- **[[智能体视频剪辑|智能体视频剪辑]]的流水线五步**：媒体理解(看懂素材 + 转录语音)→ 创意方案(先给用户确认再动手)→ 沙箱执行(技能 + 子流程)→ 用 Remotion 写成代码合成 → 验证层检查可渲染性，有问题就迭代。
- **「剪辑比生成更难」**：生成是空白画布随便画，剪辑要智能体自己挑最佳片段、决定取舍，还要在素材凌乱时交付观众分不出人机的专业成品。
- **品味沉淀在「技能」里**：剪辑规则、字体搭配、B-roll 生成方法，这些是智能体手艺的载体，也是产品差异化的核心。
- **让智能体写视频代码**：选 Remotion(用 React 写视频的开源框架)的逻辑是——智能体最擅长写代码，那就让它们用写代码的方式做视频。
- **大众化的三板斧**：移动优先、方向性模板(零提示词也能用)、传统编辑器兜底做微调。
