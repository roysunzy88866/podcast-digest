# ADR 0029 · 对标「跨国串门儿计划」:它选过的期必收

- 状态:**待「需求通过」**(用户 2026-10-09 睡前明示目标;开关 CGC_ALIGN 默认关)
- 类型:**standard-change(用户授权 2026-10-09 目标)** —— 对它选过的期绕过品味判官与时效规则(ADR 0026 / drift #78 口径)
- 关联:需求共识「对标跨国串门 · 每期对齐」节 · 需求共创/调研-对标跨国串门-2026-10-09.md · 调研-同类产品摸底.md §8.5 · drift #109 · user-stories C43

## 背景
用户:「我总觉得你的内容源其实不如跨国串门计划抓的内容源好……让每天每期的内容都能跟他对齐。」
对比(近 60 天):它 94 期,我们有约 30 期;漏掉的大头是没订的节目(Huberman / All-In / Acquired / David Senra / 各类 YouTube 频道),其次是题材口径(约 1/3 非 AI)与时效规则拦掉的老内容。

## 决定
1. 每个 cron 班(在补回之后、每日顶量之前)读它的 RSS,近 14 天上的每期解析「节目 · 原标题 · 原日期」。
2. 找原集:已订源 feed(标题 ≥0.6 或原日期 ±2 天唯一一期)→ Apple 播客目录单集(标题 ≥0.75 + 节目名 + 原日期 ±3 天)→ 都没有则写 data/cgc-youtube.json 交 Mac mini(patrol-talks 搜 YouTube 落种,种子标 must)。
3. 它选过 = 必收:processBackfillPicks(must) / 种子 must → 不过判官,只留痕「对齐必收」;事实层、金句闸门照旧。
4. 没订的节目落 data/cgc-sources.json 当「对齐专用源」:不进日常新集轮询,只供 id 反查(补活/重试/音频中转)。
5. 不对齐:混剪/系列/超 240 分钟。每班最多 4 期播客版;进度记 state.cgcAlign[guid]。

## 理由
- 选题归用户;用户明说它选的都是想要的。只用公开选题单,不碰它的中文成品(版权 + 双重失真)。

## 代价 / 限制
- 站上会出现健康/投资/历史类内容(只限它选过的期)。
- 每天多 1–2 期长访谈的 ASR,班次时长受预算约束,排不下的顺延。
- YouTube 那一半依赖 Mac mini 开机;标题/日期匹配认不出的不硬猜(记「没找到」)。
