# ADR 0016 · 图谱降级:首页与导航不给图谱入口,只在单集页留一跳小邻域

- **状态**:🟡 **草稿,待用户明文确认**(2026-07-26 起草)。确认前 C13e 不得上线。
- **相关**:`需求共创/UI交互重做-2026-07-25.md` 🔒 拍板 #14;`需求共识.md` **US-10「全局图谱漫游」P0**;C6(关联导航片)、C10(首页交互改版 · 图谱去杂)
- **⚠️ 这是「砍核心能力」级改动**:推翻标 🔒 的 P0,须**用户明文 + 改共识 + 记 ADR**三件齐全。本 ADR 只完成第三件。

## 背景

C6 做了三样关联:相关单集、局部关系图、**全局图谱页**;C10 又给图谱"去杂"(只留集↔8 大类的主题网,实体页 unlisted)。

`需求共识.md` 自己就给全局图谱标注过「价值存疑,先做后看」。2026-07-25 UI 重做时,用户三选一**明选降级**。

## 决定

1. **首页与全站导航不给图谱入口。**
2. **单集页底部保留「这一集连到谁」的一跳小邻域图**(只画直接相邻的实体/集,不做无限漫游)。
3. **全局图谱页保留可访问,但不在界面上推**(不进导航、不进首页)。
4. `需求共识.md` 的 **US-10 由 P0 降为 P2**,措辞改为「**在单集页能看到这一集连到哪些人/公司/概念**」——去掉"全局漫游"。

## 为什么

- **"先做后看"已经看过了**:做完之后没有任何一条使用场景需要从全局图谱进入。用户勾的两个场景(坐下来精读 / 碎片扫)都不是"逛关系网"。
- **关联的真实价值在"顺藤摸瓜",不在"看全景"**:实测 —— 公司/概念会随集数累积(Anthropic 15 集、OpenAI 9、智能体 22),**人物不会**(53 人里 50 人只出现 1 集)。所以有用的是**从这一集跳到相邻实体**,而不是俯瞰整张网。
- **千集下全局图谱会变成毛线球**:节点随集数线性增长,可读性反向下降;而它又是构建产物,越大越慢。
- **不删只藏**:图谱页仍在,好奇的人仍能访问;将来想恢复入口只是加一个链接。

## 代价 / 残余风险(须用户知情接受)

- **全局图谱成了"没人会发现的页面"** —— 等于它的构建成本(时间/体积)基本白付。若日后确认永远不用,应另做决定把它彻底移除(**本 ADR 不含该决定**,只降级不删除)。
- 实体页(人物/公司/概念)仍 unlisted,只能靠集内双链与搜索到达 → 这些页面的曝光进一步降低。
- ⚠️ **与另一个悬案耦合**:人物页去留(动到 US-8/US-9 两条 P0)**至今未拍板**。实测 46 位人物里 44 位只出现在 1 集,点进去比来时那页信息还少。图谱降级不解决这件事,别把两者混为一谈。

## 落地位置(C13a)

- 首页模板与导航:无图谱链接
- 单集页底部:一跳邻域图(沿用 C6 的局部关系图实现)
- 原型参照:`需求共创/原型/index.html`(无图谱入口)

## 待用户确认的一句话
