# ADR 0019 · 手机端两处覆盖锁定:搜索改图标 + 详情返回键(history.back)

- 状态:已接受(2026-08-08,用户明文:设计稿手机端两轮批注逐条验收,拍板「手机端搜索改右上角图标」)
- 关联:🔒 US-3(需求共创/需求共识.md · 搜索不降级)· 需求共创/风险登记.md 风险2(中文搜索质量)· 设计稿 commit 9d28d591(手机端两轮批注落地)· 切片 C13a

## 背景

🔒 US-3 定「列表页顶栏搜索框(各页可达)」,C13a 移植时进一步定手机端 = **摊开的真输入框**(`.mhs input`,不是小图标),理由是「搜索与主题入口不降级」。落地形态:手机首页顶部常驻一条大搜索框,键入转发给 Quartz 原生搜索索引。

用户在设计稿手机端批注实测后拍板:那条常驻大搜索框「一进页面就杵着容易误触弹键盘」,占掉首屏版面。要求改成**右上角一个放大镜图标**,点开才进搜索。

## 决定

1. **手机端搜索由「摊开输入框」改为「顶栏右上角图标」**:去掉首页/必读页那条摊开的 `.mhs` 大搜索框;改让顶栏里 Quartz 原生搜索按钮(`.pd-acts .search .search-button`)在手机端以 40×40 图标形态出现,点开即 Quartz 自带**全屏搜索模态**。
2. **搜索本身不降级**:仍是完整输入 + 实时结果,复用 Quartz 的中文索引(不自建、不砍功能)。变的只是入口形态(常驻框 → 图标 → 全屏搜索),不是搜索能力。US-3 的验收 Gherkin(输入关键词→命中标题/人物/概念、无结果不报错)仍全部成立。
3. **桌面不变**:桌面端顶栏仍是那条长搜索框(`.pd-acts .search-button` 的 calc 宽度样式一行不动)。
4. **旧的「摊开框下拉」覆写退役**:C13a 为把 Quartz 结果面板塞成「摊开框正下方的下拉」而写的一组手机端覆写(藏 `.search-container .search-bar`、`search-space` 上移 118px、去 backdrop-filter 等)与配套的 `wireSearch` 转发脚本一并移除 —— 它们会破坏原生全屏模态(把模态自己的输入框也藏了)。

## 理由

- 「图标 → 全屏搜索」是主流手机搜索形态(省首屏、避免误触弹键盘),而搜索能力本身不缩水。
- 用户在真实手机批注下亲验拍板,判断权在用户(体验类)。

## 影响

- **仅手机端**(`@media max-width:1023px`);桌面端零改动。
- 首页/必读页手机首屏收回一条搜索框的高度,让给主题药丸与卡片。
- 大类页/详情页顶栏本就不放搜索(维持现状),不受影响。
- 退役 `wireSearch` 与「摊开框下拉」覆写,配套单测按新形态改写(标注配合本次 UI 改动)。

## 追加决定(2026-08-08)· 手机端详情页返回:「← 返回」(history.back)替代 logo 返回

### 背景
2026-08-01 曾拍板「手机端详情页返回键位置放 logo」(点 logo 回首页),撤掉「← 返回」文字键(见 drift-log #45 / custom.scss 详情块旧注)。
用户 2026-08-08 明文澄清 PC 与手机是**两套交互范式**:
- **PC**:点 logo 返回;点卡片 = **跳页面**(传统页面导航)。
- **手机**:点卡片 = **不跳页面、进入下一级**(钻取式);点 **「← 返回」= 回上一级**。

### 决定
手机端详情页顶栏:**显示「← 返回」文字键、藏站名 logo**;点击 = `history.back()`(回真正的上一级,而非死链回首页)。**PC 一字不动**(logo 返回 + 卡片跳页)。
实现:`render.mjs` 保留 `.pd-back href="/"`,由脚本块**委托监听**(非内联 onclick,避 CSP unsafe-inline):手机端(`innerWidth<1024`)且历史栈非空 → `preventDefault()+history.back()`(回上一级);历史栈空(外站/新标签直开)或桌面 → 走默认 `href="/"` 回首页(不留死胡同,GLM 20260808-002[2] 兜底)。`custom.scss` 手机详情块显示 `.pd-back`、隐藏 `.b`。

### 理由
手机是层级钻取模型(进下一级 / 回上一级),logo-回首页不符合「回上一级」的心智;用户明文拍板(交互类判断权在用户)。

### 影响
仅手机端详情页;桌面零改动。覆盖 08-01「logo 当返回」决定(drift-log 同步)。
