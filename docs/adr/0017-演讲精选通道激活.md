# ADR 0017 · 演讲精选通道激活(源清单 v1 → v1.1 演讲精选批次)

- 状态:已接受(2026-07-31,用户明文「圈定清单这个流程你走下去」)
- 关联:需求共识 INPUT 🔒 ②(YouTube 独占兜底)· 订阅源清单 v1 🔒 · `需求共创/调研-新源候选-2026-07-24.md`(2026-07-31 增补节)· 切片 C16

## 背景

用户 2026-07-31 点名「看看还有哪些演讲可以抓进来,比如黄仁勋的演讲」。两路调研 agent(人物路+频道路)产出候选并落盘调研文档增补节;头号发现=AIEWF 2026 演讲潮(7-08 起上传)落在 7-24 上轮调研盲区。

**共识复核更正**:7-24 调研文档称「演讲进流水线撞共识(共识锁播客访谈形态)」——经逐条复核不成立:INPUT 🔒 ② 明写「YouTube 频道(官方 RSS/WebSub 发现 + yt-dlp 获取)只兜底 YouTube 独占内容(如 AI Engineer 大会演讲)」,且 AI Engineer 本就在源清单 v1 的 12 源之内,只因 CONSTRAINTS ④(yt-dlp 需住宅 IP,云 runner 跑不了)第一版搁置未接线。故本决定属**激活既有共识通道**,非新内容形态突破。

## 决定

1. **形态 = 精选批次,非频道全订**:人工圈选具体演讲(调研→用户拍板→批次接入),不做 YT 频道自动巡航(风控 + 品味双重原因)。
2. **首批 = 演讲精选批次 v1,12 条**(完整表含链接/时长/对味度 = 调研文档 2026-07-31 增补节,此处不重抄):黄仁勋×3(Axios/Hoover/LangChain)+ AIEWF×5(Theo 闭幕/OpenAI 黄金时代/Garry Tan/Claude Code 团队/长时程任务)+ Config 2026 keynote + Stripe×Replit + Dario Bloomberg + Collison×Amjad。红杉 Dynamo 待查重 TD feed 后补入或除名。
3. **获取通道 = 本机 yt-dlp 抓一手 → 云端接力**(用户亲证本机可抓;云 runner 抓 YT 接近必然被封,`调研-内容获取可行性.md`):本机下音频+元数据 → 送云 → whisperX 转写 → 现有防失真链全链照跑,闸门一分不降。
4. **去重三层**:video ID 进 pipeline-state 账本(全局唯一);标题归一化与库内 title_en 模糊比对,疑似重复进待裁不自动处理;**有 RSS 版的一律走 RSS**(实证:红杉频道≈Training Data feed 镜像;YC 两条 Jensen/Altman 音频版已在库)。
5. 实现开新切片 **C16**。

## 后果

- 版权敞口同既有口径(ToS 灰色自担,用户已明文,drift #17 公开站同款)。
- 成本:每条演讲 = whisperX 转写(runner 时间,免费)+ GLM 翻译/浓缩(同播客集量级);12 条一次性批次。
- 演讲无「说话人分离」需求弱化(多数单讲者),转写反而比多人访谈干净。
