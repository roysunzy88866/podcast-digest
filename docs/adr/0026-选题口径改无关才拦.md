# ADR 0026 · 选题口径从「对味才收」改为「无关才拦」;核不实删句照发

- 状态:**待「需求通过」**(用户 2026-10-04 弹框拍板四项;按全局约定上线档改需求须查漏全绿 + 用户亲口「需求通过」后开工)
- 类型:**standard-change(用户授权)** —— 改品味判官口径(`需求共创/内容品味档案.md` + taste-judge / 演讲巡航判官)与防失真闸门的**处置方式**(不改「查什么」)
- 关联:ADR 0013(防失真闸门口径)· drift #26 / #78(时效 14 天 + 60 天窗口)· drift #107(Scenario 5d-C/5d-D 删句兜底)· 需求共识「选题与拦截口径 v2」节

## 背景

用户 2026-10-04:「我希望把每一个播客都弄进来。现在的问题是,你会因为一些鸡毛蒜皮的小事情,挡住一些很重要的东西……拦的话,应该是要拦掉那些与我无关的话题。」

近 30 天实账(judge-log / pipeline-state skipped,2026-09-04 起):
- 品味判官判 412 集,拒 140(34%);其中 **48 集理由是「拿不准」**(如 a16z Ben Horowitz「Who Grades the AI Models?」、Brad Gerstner 访谈),12 集「过时」,其余多为真无关(NFL、电动飞机、TypeScript 7)。
- 事实层闸门整集隔离约 20 集:Richard Socher、Michael Moritz、Keith Rabois、YouTube CEO Neal Mohan、Brian Chesky、Hugging Face 联创、No Priors 芯片等——多为一两句核不实整集被毙。
- GLM 内容审查 [1301] 整集放弃 2 集(Founders 扎克伯格等)。
- 产能:近两周日产峰值 16 集,订阅源新集约 14 集/天 → 收得下。

## 决定(用户 2026-10-04 拍板)

1. **只拦三类「与我无关」**:① 非 AI/科技的泛话题(体育、健康养生、政治时事、个人理财、传统行业等)② 多话题新闻速览(一期拼三四条新闻的周报/快讯体)③ 学术研究 / AI+生物科研(偏论文、算法原理、AI 做科研)。
   - **「大模型发布/跑分评测」移出拦截类 → 收**(用户这次没勾)。
2. **拿不准 → 收下**(原「拿不准判不发布」作废)。判官调不通照旧放行(fail-open 不变)。
3. **核不实 → 删掉那几句照发**:事实层闸门照查(查什么不变),处置从「定点重写救不动 → 整集隔离」改为「删掉核不实的那几句,其余照发,日志逐条留痕」;**删除量超过正文 1/5 → 整集重做一次浓缩**,重做仍超才隔离。drift #107 的「≤2 处」上限随之放宽为「≤1/5 正文」。
4. **时效维持现状**:时效性题材 14 天过时规则 + 补历史 60 天窗口不变(模型发布类 14 天内收、超了照旧算过时)。

**我(Claude)定的技术配套(📌)**:GLM [1301] 拒译 → 只跳过被拒段落/换模型重试,不整集放弃;转瞬失败与超长集 → 换路重试不放弃;YouTube 频道附加规则(judgeHint)同步改成同一口径;过去 60 天因「拿不准 / 大模型发布 / 事实层」被挡的集按新口径重审补回。

## 理由

- 选题口径与「谁能看到什么」是体验判断,归用户;用户明确要「宁多收、只拦无关」。
- 防失真底线不降:核不实的句子**仍然不会出现在站上**(删掉而不是放行),只是不再连坐整集;引语逐字命中这条硬拦不变。

## 代价(用户知情)

- 站上会多出一些用户不太感兴趣但不算无关的集(拿不准收下的那部分);每天量从 ~10 涨到 ~12–14。
- 删句后个别段落会少一两句话,读起来可能略跳。
