# 设计稿 · 唯一真相

> **这个文件夹是本站界面的唯一设计真相。** 2026-07-27 用户拍板从 `需求共创/原型/` 抽出来独立成档。
> 别处任何 HTML 都不是设计稿 —— 见下面「不算数的东西」。

## 为什么要独立成档

在此之前有两份东西都被当成「设计稿」,而且互相打架:这一套(带批注落地的原型)和
`需求共创/canvas-单集页.html`(更早的**结构稿**)。我照着其中一份做、用户对着另一份看,
结果就是「线上和设计稿区别很大」。**一份稿、一个地方**,这个文件夹就是那个地方。

## 这套稿是怎么来的

`index.html` / `ep-*.html` / `cat-*.html` / `must-read.html` / `all.html` 是**手改落地**的成品 ——
用户在网页上用批注工具提了**八批**修改,每一批都直接改进 HTML。它同时是视觉稿和交互稿:
配色、字号、间距、交互行为都以它为准。

## 怎么继续用「标注」改设计

```bash
python3 设计稿/serve.py
```

然后浏览器打开 http://localhost:8123 。点右下角「批注」进标注模式 → 点页面上任何东西 →
写一句要改什么 → 保存。批注同时存两处:浏览器本地(刷新不丢)+ 回传到
`/tmp/uiproto-comments.jsonl`,Claude 直接读那个文件,你不用复制粘贴。

服务没起来时会自动降级成「只存本地」,面板里可一键复制全部 —— 但那样 Claude 读不到,
所以**改设计前先把 serve.py 跑起来**。

## ⚠️ 三个陷阱

1. **`_build/` 里的 Python 生成器已经生成不出现在的 HTML 了。**
   八批修改全是直接改 HTML 落的,**重跑生成器 = 全部回退**。详见 `_build/README.md` 顶部红字。
2. **`covers/` 缩略图不入仓**,需要时用 `bash 设计稿/make-covers.sh` 一键重建。
3. **`comment.js` 只属于设计稿,不属于真站** —— 上线时不部署它(C13e 已列为上线前必查项)。

- `需求共创/canvas-单集页.html` —— 更早的**结构稿**,它自己开头就写着「配色/字体/间距全部不算数,
  只看有哪些块、顺序对不对」。站名(英文播客中文精华)、顶栏导航(主题/人物/关于)、
  钩子样式都是旧的,**已被本文件夹里的批注版覆盖**。唯一还有参考价值的是它画出了
