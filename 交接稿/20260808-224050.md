## 七、关键操作纪律(本项目最易踩)

- **推送前必单独一条命令查 `gh run list` 有无 run 在跑**(有 run 在跑不许推,竞态血账铁律);**查与推不许写进同一条复合命令**。网络走代理 `https_proxy=http://127.0.0.1:7877`(clash 端口 7877,非 7890)。
- **改代码后 GLM 闸门**:改了代码不过 `glm-check --kind code` 冷喂复核 + `adjudicate` 打裁决,Stop 钩子不让收尾。改「标准定义段/闸门/测试口径」必带 `[standard-change: 用户授权]`。
- **commit 用 `--no-verify`**(本地缺音频 pre-commit gate 必挂,已有 allow 规则);commit-msg 格式 `[fix|docs|chore|adr] 描述`。
- **内容处理只云端跑**,本地 Claude 只修 bug/管仓/移植;真站没法本地起预览(要 clone Quartz),验线上用 curl-mirror 法。
- **改 🔒 锁定项**必走:用户明文 + 改共识 + 记 ADR,不偷改。
