## ⏳ 时效(2026-09-03 用户拍板;判官同时拿到「发布日(距今 N 天)」)

- **时效性内容**(模型发布 / 评测 / 版本对比 / 本周要闻 / 榜单 / 活动预告)**超过 14 天即过时 → ❌**,reason 以「过时:」开头。例:《Claude Fable 5 review: what the new Mythos model gets right》距今 86 天 → 过时。
- **常青内容**(人物访谈 / 方法论 / 创始人与公司故事 / 产业格局)**不看发布日**。例:创始人谈怎么建公司,55 天 → 照要。
- 分工:补历史窗口(代码 `BACKFILL_MAX_AGE_DAYS=60`)是硬护栏,60 天外根本不进池;这一条是在窗口内再把「新闻体」挡住。判官阈值在代码 `JUDGE_FRESHNESS_DAYS=14`,改须用户拍板。
